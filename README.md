## ⚠️ 三条硬规则

1. **编号必须核实。** 本库中每一条 arXiv 编号、标准号、报价，都必须打开原始页面确认过标题与作者。
   未核实的写 `⚠️未核实`，**不要凭记忆写编号**。这条规则来自一次真实教训：调研中发现的 4 个论文编号里有 3 个指向完全无关的论文。
   完整流程见 [[100-物理AI产品与领域/000-专家作业标准-四问#五-落地为默认流程编号核验清单]]。

2. **LLM 不产出数值。** 应力、应变、温度、寿命、重量、GCI——一切进入工程决策的数值，
   必须由确定性求解器计算。LLM 只做意图解析、代码生成、编排、解释、检索。
   详见 [[100-物理AI产品与领域/020-领域知识/LLM在物理仿真中的角色边界]]。

3. **没有元数据的结论不能支撑高后果决策。** 结果必须随附：求解器版本、网格、输入卡、
   材料卡、边界条件、收敛历史、GCI 研究、后处理脚本。缺了追溯链，一次交付事故就会毁掉全部信任。
