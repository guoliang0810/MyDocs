## ⚙️ Obsidian 配置建议

### Daily Notes 指向 `600-工作日志与记录/`

```
Settings → Core plugins → Daily notes
  Date format:      YYYY-MM-DD
  New file location: 600-工作日志与记录
  Template file:    500-模板与规范/FDE工作日志模板
```

### Templater 变量

工作坊模板使用 `{{title}}` / `{{date}}`，配合 Templater 插件：
`tp-` 前缀的旧命名已废弃，现用语义化文件名。
