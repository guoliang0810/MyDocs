# 工作日志与记录

> **FDE 的一手记录都在这里。** 日志不只是流水账——
> 它是"**算不出来的工况**"和"**回流到产品的资产**"这两个 KPI 的唯一原始记录。

---

## 📅 日志约定

- 用 Obsidian **Daily Notes** 插件自动创建，格式 `YYYY-MM-DD`
- 模板：[[500-模板与规范/FDE工作日志模板]]
- 每篇至少写清：**今日重点（一件）** + **回流资产**

---

## ⚠️ 两栏不许空

| 栏目 | 为什么 |
|---|---|
| ⭐ **算不出来的工况** | 客户和监管方都会问。只交成功算例 = 把风险留到客户现场爆发 |
| ⭐ **回流到产品的资产** | FDE 的核心 KPI。空栏意味着这个项目只是三个项目，不是行业知识资产 |
