# 职业档案总纲（v2.0 重构版）

> **一句话定位（对外用）**
>
> **物理 AI 工业软件领域的产品负责人 + 前置交付工程师（FDE）。**
> **在客户现场把"能不能算"翻译成"敢不敢签字"，并把签字过的东西沉淀回产品。**
>
> 双轨求职：**FDE / 解决方案架构师**（主攻） + **大客户销售 / 技术销售**（备选）。

## 二、双轨定位（本次重构的核心决策）

> **为什么是双轨，而不是二选一？**
> 因为 FDE 架构师与工业软件大客户销售，在真实企业里**往往是同一个岗位的两种配置**。
> 而我在这两条路上的**共用资产是同一套**。

| | **FDE / 解决方案架构师**（主攻） | **大客户销售 / 技术销售**（备选） |
|---|---|---|
| **本质** | 在客户现场把模糊需求变成可验收的方案 | 在客户决策链上把方案变成合同 |
| **核心 KPI** | PoC 转正率、交付一次验收通过率、回流资产数 | 新签额、赢单率、回款、客户续约 |
| **我最强的一段** | 清航飞迈产品负责人 + FDE（当前） | ⭐ 2021–2022 办学校：**从 0 建立一套能跑的业务体系** |
| **最大缺口** | CAE 求解器实操深度、V&V 体系 | ⭐ **可独立开发的客户资源与成交记录** |
| **薪资参考** | 国内 FDE 均值 40.8 万 / 中位 36.6 万；CAE 售前岗多为 15–30K×13 | 工业软件销售底薪 8–20K + 提成，区间 20–80 万/年 |
| **可迁移性** | 高：FDE 可转售前、可转解决方案 | 高：销售可转 FDE 的"商务侧" |

> ⭐⭐ **关键结论：以 FDE/解决方案架构师为主线投递，以大客户销售为并行选项。**
> 理由有三：
> 1. **可核验性更强。** FDE 的能力可以用"交付物、方案、验收标准"证明；销售的成交记录在我这里**尚不存在**（无独立签约业绩）。
> 2. **人岗匹配度更高。** JD 原文反复出现的硬门槛是"能写方案、能讲、能落地、能长期驻场"——这正是本库 [[100-物理AI产品与领域/020-领域知识/FDE角色与工作标准]] 已定义的能力。
> 3. **薪资与天花板更高。** FDE 岗位在国内仍处政策红利期（工信部 2026 年 8 月专项通知明确"鼓励服务商搭建 FDE 团队"），供给缺口 0.28。

## 三、⭐ 六条硬规则（就业版）

1. **数字必须能追到源头。** 简历上每个数字，必须能回答"这个数怎么来的、谁记录的、在哪能核"。
   没有源头的数字一律删掉，不做"看起来合理"的估算。

2. **⚠️ 未澄清项绝不上简历。** [[50-风险与合规/简历风险处置清单]] 里的 5 项硬冲突，在本人确认前，
   **任何对外材料不得出现相关表述**。这不是谨慎，这是止损——背景调查会问到。

3. **能力—证据—结果三段式。** 每条能力陈述必须能落到一个可交付物 / 一个可核验数字 /
   一个可被追问的现场细节。三者缺一，就是"包装"而非"证据"。

4. **区分"做过"与"负责"。** 面试官会追问"这个决策是谁拍的"。做过的事要说清边界，
   负责的事要说清代价与取舍。**夸大规模比缩小规模更容易被击穿。**

5. **驻场与出差是必要条件，不是加分项。** 国内 FDE 岗位 JD 普遍写明"长期出差与驻场，
   时间占比可能高达 50% 或以上"。面试时主动确认，��掩饰，会在入职后以离职收场。

6. **⭐ 不为"看起来像大厂"而模糊主体。** 背调查的是**雇佣主体**、**社保记录**、**离职证明**。
   模糊表述在初筛时可能有用，在背调阶段是致命伤。**宁可写得小，不可写得虚。**
