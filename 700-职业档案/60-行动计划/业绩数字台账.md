# 业绩数字台账 · 模板

> ⭐⭐ **这份台账是"求职期间唯一不能停的事"。**
> 因为这些数字**只在在职时产生**——离职后永远拿不到。
> 而它们是简历里唯一有说服力的部分。

---

## 一、填写纪律（三条，不可违背）

| # | 纪律 | 反例 |
|---|---|---|
| 1 | ⭐ **只记能说出口的数**——每个数要能解释口径、分母、测量方法 | ❌ "效率提升明显" |
| 2 | ⭐ **没有基准对比的数字不记** | ❌ "交付了很多项目" |
| 3 | ⭐ **脱敏**——不记客户敏感信息，只记可公开的量级与行业 | ❌ 客户名称、型号、图纸数据 |

> ⚠️ 违反第 1 条的代价：面试时被追问口径答不上来 = 整个简历可信度归零。
> 宁可空着，空着是"待补"，错着是"造假"。

## 四、⭐ 转化规则：台账 → 简历

| 台账字段 | → 简历句式 | 注意 |
|---|---|---|
| 主导 PoC 数 + 转正率 | "主导 __ 个 PoC，其中 __ 个转为正式合同" | 分子分母都要给 |
| 一次验收通过率 | "交付物一次性验收通过率 __%" | 必须说明分母定义 |
| GCI 实际水平 | "交付方案网格无关性 GCI ≤ __%" | 用 ≤ 不用 = |
| 试验对标偏差带 | "关键输出量相对试验偏差 ≤ __%" | 同上 |
| 交付周期 | "典型交付周期 __ 天" | 附口径：从哪到哪 |
| 回流资产数 | "累计回流 __ 项可复用资产（L1 __ / L2 __ / L3 __ / L4 __）" | ⭐ 这是 FDE 与外包的分水岭 |
| 客户节省时间 | "为客户节省 __ __ 小时/周期" | ⭐ 没有基准就不写 |

> ⭐⭐ **写法禁忌**：
> ❌ "覆盖核心接口 98%" → ✅ "覆盖 __ 类核心接口"
> ❌ "效率提升 60%" → ✅ "从 __ 降到 __（口径：__）"
> ❌ "零故障交付" → ✅ "验收一次通过率 __%（分母 __ 次评审）"

## 五、⭐ 为什么这个台账是"求职期间优先级最高的技术任务"

| 理由 | 说明 |
|---|---|
| **不可回溯** | 数字只在在职时产生。离职后再补 = 永久缺失 |
| **替代不了** | 培训、认证、自学项目都替代不了"在真岗位上真做过" |
| **成本极低** | 每月 30 分钟 |
| **收益极高** | ⭐ 它决定简历是"做过"还是"负责过"。**"做过"和"负责过"在市场上差一个薪资档** |
| **与能力地图联动** | 它同时是 [[20-能力与证据/能力证据矩阵]] 里所有 🅱 实证项的证据来源 |
