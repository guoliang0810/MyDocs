# 背景调查应对

> **认知：背调不是"审判"，是"求证"。**
> 背调方要回答的问题只有一个：**这个人简历上写的，是不是真的。**
> 所以策略不是"怎么躲过去"，而是**"让求证过程顺利得到正确答案"**。

---

## 一、背调到底查什么（依据国内主流第三方背调机构公开作业流程）

| 层 | 动作 | 说明 |
|---|---|---|
| **① 授权** | 候选人签署《背景调查授权书》，明确调查范围 | ⚠️ **无授权不得调查**——这既是保护我的，也是我拒绝非授权调查的依据 |
| **② 身份核验** | 身份信息与官方数据比对、人像核验 | 身份证 |
| **③ 学历核验** | 学信网学历 / 学籍 / 学位查询；境外学历查留服认证；技能证书核验 | ⚠️ 学历造假在《劳动合同法》下属**欺诈订立劳动合同**，用人单位可主张合同无效并解除 |
| **④ 材料核验** | 离职证明、劳动合同关键信息比对（公章、时间、岗位） | ⚠️ **公章造假是刑事风险**，必须用原件 |
| **⑤ 社保交叉比对** | 比对参保单位、参保时间 → 判空窗期、重叠期、多段并行 | ⭐ **可提前自查** |
| **⑥ 前雇主访谈** | 联系最近 2–3 家 HR / 直属上级 / 同事，核：入离职精确时间、岗位名称、汇报关系、核心职责、离职原因、是否违纪 | ⭐ **决定成败的一环** |
| **⑦ 深度访谈**（中高级 / 核心技术岗） | 多证明人深度访谈、项目真实性核查、业绩指标溯源 | ⭐ 我当前岗位属于"核心技术岗"，**大概率会走到这一层** |
| **⑧ 工商与公开信息** | 判断所述任职企业与岗位是否合理；公司存续状态、经营范围 | 国家企业信用信息公示系统 |
| **⑨ 合规筛查** | 竞业限制协议在否、保密义务、商业行为冲突 | ⭐ **在职投递必查** |

## 二、⭐ 五个必须主动做的动作

### ① 先自查社保（唯一由你完全掌控的渠道）

**路径**：国家社会保险公共服务平台（个人可查全部参保单位与缴费月份）
或支付宝 / 微信「城市服务 → 社保查询」

**要核对的三件事**：
1. **有没有无法解释的重叠**——两个单位同月缴费
2. **有没有无法解释的空窗**——尤其 2021.09–2023.07（古旧书离职 → 迪威特入职）
   ⭐ 这段空窗 ≈ 21 个月。**面试会被问"这段时间你在做什么"，必须有一致且真实的答案。**
3. **单位名称与简历是否一致**——分公司名称必须完整写出

> ⚠️ **重叠是红线**。如果发现与现公司的社保期间在简历上被拆成两段，
> **必须现在就改口径**，不要等背调查出来——那时会被定性为"隐瞒任职"。

### ② 提前 1–2 周告知前主管

**打电话时怎么说**（这是最关键的一段话）：
> "X 哥/姐，我最近在看新的机会，可能有公司会做例行背景调查，
> 会给您或 HR 打个电话核实我离职时间、岗位和主要工作内容。
> 想提前跟您说一声，也想请您帮我确认一下我这段经历里有没有需要补充的地方。
> 我在任期间主要负责 ___，___ 部分是 ___ 团队一起做的。"

**为什么有效**：背调电话打过去时，对方第一句话往往是
"**我已经跟他说过了**" 或 "**我不知道他离职了**" —— 这两种回答的差别是致命的。

### ③ 查现公司竞业条款

- 在职证明、劳动合同、员工手册中检索"竞业限制"条款
- 若有限制：核查限制范围（是否覆盖目标公司）、期限、补偿金标准
- ⚠️ **竞业期内入职竞对可能构成违约**，严重的会被追究赔偿责任
- **若目标公司就是竞业对象**，先评估法律风险再投

### ④ 准备"项目真实性核查"材料

深度访谈会问："这个项目具体怎么做的？遇到了什么问题？"
⭐ **准备物**：脱密后的方案截图、流程图、报告目录、验收清单、失败复盘记录。
⚠️ **注意脱密**：现雇主的客户名单、数据、图纸不可外泄。
**讲方法、讲结构、讲角色边界，不讲具体客户的敏感数据。**

### ⑤ 把"边界"主动交代清楚

深度访谈最爱问的是**边界问题**："这个是你做的还是团队做的？"

> ⭐ **最好的策略是主动说**："项目是 A 团队牵头的，我负责其中的 ___ 模块，
> ___ 部分是 __ 做的。" ——这比被追问出来更像一个可信的人。

## 三、⭐ 五个高风险回答（背调电话/深访时）

| 场景 | ❌ 危险回答 | ✅ 正确回答 |
|---|---|---|
| 离职时间 | 含糊"大概吧""记不清了" | 给**精确到月**的时间，并说明确定依据（离职证明/交接单） |
| 薪资 | 含糊或夸大 | 给区间 + 说明含不含提成/奖金 |
| 项目归属 | 全说"我负责" | ⭐ 主动划分边界 |
| 离职原因 | 抱怨前东家 | 中性向前："当时想找更贴近 ___ 的场景" |
| 被裁 / 被辞退 | 隐瞒 | ⭐ 坦白："项目收缩，岗位调整"，并说清是组织调整还是个人原因 |

## 四、⭐ 三种背调结论的应对

| 结论 | 含义 | 我的应对 |
|---|---|---|
| **一致** | 全部核实通过 | — |
| **部分差异**（日期差 1–2 月、职位名称略异） | 常见，非致命 | 主动说明原因（"离职手续走了 X 月，实际交接到 Y 月"） |
| **重大不一致**（"没这个人"/"不是这个岗位"） | ⚠️ 高危 | ⭐ **立即联系背调方与对方澄清**，提供劳动合同/离职证明原件；同时复盘该段在简历中的写法 |

> ⭐⭐ **一条反直觉的经验**：
> **背调发现"差异"时，最有效的动作不是解释，而是出示文件。**
> 纸面证据（劳动合同、离职证明、社保记录、工资流水）比任何口头解释都有力。

## 五、☐ 背调准备清单

```
[ ] 社保记录已自查，重叠/空窗已能解释
[ ] 学历证书、学位证已归集（学信网可查）
[ ] 离职证明、劳动合同已归集（若已离职）
[ ] 身份证明已归集
[ ] 职业资格证书已归集（六级等；无则简历不写）
[ ] 竞业条款状态已确认
[ ] 最近 2 家前主管/HR 已提前告知
[ ] 4 个 STAR 案例的脱敏材料已备
[ ] 各段经历的"边界说明"已统一口径（简历与口述一致）
[ ] 目标公司是否在竞业范围内已确认
```
