## 三、⭐ 能力 → 岗位 的匹配度判断

### 我真正的差异化优势

**不是"我懂测试"，而是"我同时做过 0→1 的业务体系搭建、0→1 的工程交付体系搭建、0→1 的教学体系搭建"。**

FDE 这个岗位的本质，就是**在客户现场从 0 到 1 搭出能用的东西**，并且把它沉淀回产品。
这三段经历正好是三个不同场景下的同构能力：
- 培训学校 = 从 0 搭业务体系
- 算法测试组 = 从 0 搭交付体系
- DeerFlow 课程包 = 从 0 搭知识传递体系

> ⭐ **这三条同构能力，才是"FDE + 产品负责人"这个组合的核心竞争力。**
> 纯技术背景的人做不了产品，纯产品背景的人交付不了现场。

### 最大的短板

**物理 AI 的"物理"侧。** 我的强项在"工程化、系统化、交付化"，
但对**力学/材料/求解器本身的深度**还不够。
而物理 AI 产品负责人如果不能判断"这个仿真结果值不值得信"，
就只能做传声筒——这是必须尽快补的。
