# 简历风险处置清单

> ⭐⭐ **这是整个 700 目录里优先级最高的一份文件。**
> 下面 5 项不解决，**任何版本的简历都不该投出去**。
> 因为它们不是"文档瑕疵"，是**背调可查证的硬伤**——
> 一旦被查实，结果不是"没拿到 offer"，是**信任崩塌 + 可能被列入黑名单**。

---

## 零、为什么这份文件排在所有求职准备之前

**顺序错了的代价**：很多人花 3 个月补 NAFEMS 认证、准备面试话术，
结果因为一个虚构项目在背调阶段被识破——**沉没成本归零**。

> ⭐ **求职期的正确排序**：
> **① 事实澄清（卡简历，一票否决）→ ② 简历成品 → ③ 面试话术 → ④ 能力补课 → ⑤ 证书与作品集**
>
> 第 ① 项不完成，其余四项的投入无法变现。

### ① 2023.10–2024.05 雇主主体不明

| 来源 | 记载 |
|---|---|
| `90-历史版本/简历-测试岗-2025年中` | 厦门方胜众合企业服务有限公司海淀分公司 · 测试工程师 · 车载感知算法 Pipeline |
| `90-历史版本/简历-早期版本` | 北京理想汽车有限公司 · AI 算法项目管理 · orin 台架测试、算法评测 |

**两段内容高度同源**（车载感知/自动驾驶算法 Pipeline、评测、性能测试）。
**风险**：背调会同时联系"厦门方胜众合"和"理想汽车"。若一家说不认识我，
在另一家又查不到我——这在背调报告里会被标为 **"履历存疑"**，通常是直接淘汰。

**处置方案（三选一，必须选一个并执行到位）**：

| 方案 | 动作 | 适用 |
|---|---|---|
| **A. 核实后写实际主体** ✅ 首选 | 查劳动合同/离职证明/社保参保单位，以**社保记录为准** | 任何情况下都该先做这一步 |
| **B. 若为加盟/劳务/外包主体** | 写真实签约主体，并在面试中主动一句话说明"XX 是集团/合作方的签约主体，业务在 XX 团队" | 方案 A 查出非目标公司时 |
| **C. 若两家都不认** | **整段删除**，改写为"车载感知算法测试方向（2023.10–2024.05，雇佣主体见说明）"并准备口述 | 极端情况 |

> ⭐ **验证渠道**：
> - 国家社会保险公共服务平台（本人可查全部参保单位与缴费月份）→ **这是唯一的硬证据**
> - 支付宝/微信"城市服务"→ 社保查询
> - 前雇主 HR 访谈时，**核对入离职月份、岗位名称、汇报关系、离职原因**
> - 国家企业信用信息公示系统（[gsxt.gov.cn](https://www.gsxt.gov.cn)）→ 核验公司是否存续、
>   是否为"厦门方胜众合企业服务有限公司海淀分公司"这样的分公司（分公司无独立法人资格，
>   这本身就会引发追问）

## 二、⭐ 数字审计（把历史通胀数字全部换掉）

> **原则：数字不是越多越好。数字少但每个可核验，胜过 8 个漂亮但无源的百分比。**

### 2.1 历史版本中必须删除的数字

| 历史表述 | 问题 | 处置 |
|---|---|---|
| 覆盖核心接口 **98%** | 无法核验，且 98% 这个数在行业里已被当成"随口说的" | 改为"覆盖 __ 类核心接口"，填真实分类数 |
| 单轮评测 **36h → 24h** | ⚠️ **本身合理，可保留**，但必须说清测试方法 | 保留 + 补口径（见下） |
| **1000+ 并发**、**TPS +30%** | 无口径、无环境说明 | 改为"在 ___ 环境下模拟 ___ 并发，定位到 ___ 瓶颈" |
| **准备时间 -50%** | 因果不成立（自动化脚本 ≠ 省一半准备时间） | 改为"实现测试环境自动部署、数据自动生成与结果自动分析" |
| **缺陷率 -35%** | 缺陷率口径未定义 | 删除；改为"建立代码提交—自动测试—缺陷预警链路" |
| **延迟 -40%** | 与 1000 并发场景不匹配 | 删除 |
| **学员就业率 95%** | ⚠️ 与同一业务里"全部就业"口径冲突 | ⚠️ **必须二选一并统一**：要么给分母，要么改成"负责学员就业对接" |
| **10000+ 观众同时在线** | 直播场景与古城堡/狸米经历的实际规模关系需澄清 | 核对后填真实值 |
| **回归效率 +60%**、**测试效率 +50%** | 无基线 | 删除 |
| **动画/接口覆盖 80%**、**用例 700+/120+** | 数字本身不敏感但无意义 | 改为"建立 ___ 场景用例集" |

### 2.2 ⭐ 行业量级的锚（用于自我校准）

> 本库已核实的公开数据：**Ansys 多物理场采购成交价 ¥494.7 万、Abaqus 科研版 5 并发 ¥152.6 万**
> （政府采购成交公告口径）。
>
> ⭐ **这是校准器**：一个做物理 AI 工业软件交付的人，
> 如果简历上只有"接口覆盖率 98%"，面试官会立刻判断**"他不在这个行业"**。
>
> **正确的量级示例**：
> - GCI ≤ 5%（网格无关性研究结论）
> - 目标输出量相对试验偏差 ≤ __%
> - 单工况求解 ___ 核时内收敛
> - **交付周期与实施服务周期之比**
> - **回流到产品的资产数**（L1 模板 / L2 参数库 / L3 求解器插件 / L4 API-SDK）
> - 简化假设的**影响量级**（如"去除倒角对目标量影响 < X%"）

> ⭐ **减重 150KG 这样的数字是可以留的**——因为它有公开出处（官方口径），
> 且能被追问到细节。它比"效率提升 60%"有说服力一百倍。

## 三、⭐ 背调会问什么（提前准备，别被问懵）

> 来源：国内主流第三方背调机构公开的作业流程（授权访谈 + 社保交叉比对 + 材料核验 + 工商信息验证）。

| 核验层 | 具体动作 | 我的准备 |
|---|---|---|
| **基础信息** | 身份核验；学历与学位（学信网）；职业资格证书 | 毕业证、学位证、六级证书（或不留） |
| **材料一致性** | 离职证明、劳动合同关键信息（公章、时间、岗位）比对 | 全部归集到一处文件夹 |
| **社保交叉比对** | 比对参保单位、参保时间，判断**是否空窗 / 是否重叠** | ⭐ **先自己查一遍**，不要等背调查出重叠 |
| **前雇主访谈** | 联系最近 2–3 家的 HR / 直属上级，核：入离职精确时间、岗位名称、汇报关系、核心职责、离职原因、是否违纪 | ⭐ 提前 1–2 周主动告知前主管，争取"中性正面"口径 |
| **深度访谈**（中高级/核心技术岗） | 多证明人深度访谈、项目真实性核查、**业绩指标溯源** | 项目材料准备：方案、报告、验收单 |
| **工商与公开信息** | 判断所述任职企业与岗位是否合理；公司存续状态、业务范围 | 国家企业信用信息公示系统自查 |
| **竞业与合规** | 竞业限制协议在否、保密义务、是否有商业行为冲突 | ⭐ **在职投递尤其重要**：竞业条款可能直接否决 |

> ⭐⭐ **三个必须主动做的动作**：
> 1. **先自查社保**——这是唯一由你完全掌控、且能提前发现"重叠/空窗"的渠道。
>    ⚠️ 如果确实存在与现公司的时间重叠，**必须想清楚怎么解释**，否则会被定性为"隐瞒任职"。
> 2. **投递前告知前主管**——背调电话打过去时，对方的第一句话往往是"我已经跟他说了"或"我不知道他离职了"，
>    这两种回答的差别是致命的。
> 3. **查竞业条款**——若现公司有竞业限制，投递竞对前先评估法律风险。

## 四、⚠️ 面试中的"危险题"与正确应答原则

| 危险题 | 陷阱 | 正确原则 |
|---|---|---|
| "你为什么从理想/方胜众合离职？" | 说前东家坏话 | 中性、向前看：讲"当时想找更贴近 __ 的场景"，不评价人 |
| "字节那个项目你负责什么？" | 硬撑 | ⭐ **直接承认已删除**，见上文 ③ |
| "你为什么离开清航飞迈？" | 若被查实时间矛盾 | 先把时间线理清，**答案必须与最终简历完全一致** |
| "你们的仿真结果准吗？" | 吹 | ⭐ **说限制**：讲 GCI、证据等级（方案比选 / 设计放行 / 适航符合性不同） |
| "你能带来多少签单？" | 承诺业绩 | ⭐ **给方法不给承诺**：讲我的六步闭环和已有行业理解 |

> ⭐⭐ **一条通用原则**：
> **面试时最有说服力的不是"我很厉害"，是"我很清楚我做不到什么，以及我打算怎么绕过去"。**
> 这恰恰是 FDE / 售前 / 销售三种岗位共同的核心素质。
