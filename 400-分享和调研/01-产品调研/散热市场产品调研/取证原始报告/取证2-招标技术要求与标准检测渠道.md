## A 小结：客户验收判据的 6 种语言（分类归纳）

| 判据类型 | 量化门槛 | 实例来源 |
|---|---|---|
| **绝对温度上限** | 外壳 <70 ℃；焊点温变 ≤4 ℃；灯体最高 ≤60 ℃（A-1/A-10/§A-10 球灯） | A-1, A-10 |
| **仿真-实测相关性** | 表面 ≤4 ℃、器件 ≤5 ℃；**Δk ≤0.04 W/(m·K)**；"仿真与试验同步" | A-1, A-12, A-19 |
| **热阻/流量曲线** | **ΔP–Q 曲线 + Rth–Q 曲线**；压降 kPa@温度&流量；制冷量 kW@25℃ | A-2, A-14, A-19 |
| **第三方报告 + 认可** | **CMA 标志**；**CMA 和 CNAS 双认可**；CNAS/CMA"优先" | A-9, A-10, A-11 |
| **材料参数（含温度点）** | k 在 25℃ **和** 90℃ 双点；k@500℃；k≤0.04@23±2℃；比热 ≥0.9 J/(g·K)；Δk≤0.04 | A-10, A-12, A-13 |
| **资质硬门槛** | **装备承制单位资格证书**（两证合一）+ 国军标体系；**软著 + 自主可控承诺书 + 近5年1项带验收证明案例**；**软件著作权登记证书 + 核心专利证书 + 近3年3个案例** | A-12, A-16, A-17 |

**FEMAI 的三个可操作结论**：
1. **k≈0.5 导热塑料的验收判据尚未被公开采购文件直接写明**（❌ 检索未得）。能检索到的最接近的真实条款是：导热垫 **k 1.5–6 W/m·K + shore 00 20–60 + ASTM D5470 + Hot Disk**（A-8）、散热器 **k≥200 + 比热≥0.9 + GB/T 22588**（A-10）、隔热件 **k≤0.04 + Δk≤0.04**（A-12）。**k≈0.5 的导热塑料/复材没有对应的公开判据条款** —— 这正是 FEMAI 的产品机会：**它是唯一能把"k≈0.5 材料的结构件"翻译成客户判据语言（ΔP–Q / Rth–Q / k(T) / Δk）的工具**。
2. **判据的"温度依赖"与"动态"是硬要求**：双温度点、精度 ±1℃、响应时间 <6min、循环次数。FEMAI 材料库必须是 k(T)、c_p(T)、TGA/热裂解阈值、CTE(T) 的多维数据库，不能是单点 k 表。
3. **国产化/软著/案例是准入门槛，不是加分项**：至少要给到「软著 + 自主可控承诺书模板 + 1 个带验收证明的案例」。用国家电投（A-16）和哈电（A-17）的措辞做模板。

## 全局取证结论（给 FEMAI 决策的三条）

**1. 客户验收判据 = 5 类可量化语言，不是"感觉热不热"。**
从 19 条公告里提炼出客户真正写进文件的判据，全部带数字：
- 温度上限（70 ℃ 外壳、60 ℃ 灯体）
- **仿真-实测偏差（4 ℃ 表面 / 5 ℃ 器件；Δk ≤ 0.04 W/(m·K)）**
- **热阻-流量曲线（ΔP–Q + Rth–Q；压降 kPa@温度&流量；制冷量 kW@25℃）**
- 第三方报告（**CMA 标志 / CMA+CNAS 双认可**）
- 材料参数（k 双温度点 25/90 ℃；k@500℃；比热 ≥0.9 J/(g·K)；Δk ≤0.04）
- 资质（**装备承制单位资格证书 + 国军标体系**；**软著 + 自主可控承诺书 + 近5年带验收证明案例**；**软著 + 核心专利 + 近3年3案例**）

**2. k≈0.5 W/(m·K) 的导热塑料/复材——公开采购文件里没有直接的判据条款，这是 FEMAI 的空位。**
❌ 检索未得：没有任何一条公开招标公告直接写出"导热塑料件 k=0.5"这类验收条款。能找到的最接近的真实条款是导热垫（**k 1.5-6 + shore 00 20-60 + ASTM D5470 + Hot Disk**，A-8）、铝散热器（**k≥200 + 比热≥0.9 + GB/T 22588 双温度点**，A-10）、隔热件（**k≤0.04 + Δk≤0.04 + 防凝露 + 霉菌0级**，A-12）。
**并且**：GB/T 10295-2008 要求试件热阻 **>0.1 m²·K/W**，k=0.5、10mm 厚的试件 R≈0.02 → **按此国标直接测会超范围**，需加厚或改用 GB/T 13475-2008 防护热箱法（量程至约 2 W/(m·K)，k=0.5 恰在量程内）。**FEMAI 输出 k 值时必须标注"方法 + 试件几何 + 温度点"，否则客户拿到手不可比 —— 这是个具体的、立刻可做的产品化动作。**
