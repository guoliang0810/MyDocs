# 散热市场调研 · 专家作业标准（v3）

> ⚠️ **已被 v4 替代**：[[400-分享和调研/01-产品调研/散热市场产品调研/散热市场调研-专家作业标准（v4-仪器版）]]（补排序、判据阈值、6 件仪器、偏差控制、可验收改写题）。本文保留作 v3 存档。

> **为什么有 v3**：v1 回答了"赛道值不值得进"，v2 回答了"一天怎么排"。
> 你说"不够深入"——对的，前两版都在**流程层**。这一版进到**专业层**：
> 每一条都回答三个问题——**专家具体做什么动作、用什么材料、不做会得出什么错误结论**。
>
> **读法**：§2 是核心（24 个专家动作，每个都带"不做的后果"）；§3 是素材（按"离真相的距离"分四环）；§4 是方法与工具（含"专家不用的工具"）；§5 是验证（含"怎么设计一次让第三方无法反驳的验证"）；§8 是改写后的题目。

| # | 前提 | 若不成立 |

## 1. 先把五个"专家才会问的问题"摆出来

市场调研做得浅，通常不是查得少，是**一开始问错了问题**。专家在动手前会先问这五个：

| #   | 专家的问题                                   | 浅层调研会问成什么   | 为什么这个问法决定成败                                  |
| --- | --------------------------------------- | ----------- | -------------------------------------------- |
| Q1  | **钱在开发流程的哪一环？**（设计 / 样件 / 模具 / 试验 / 认证） | "散热市场规模多大"  | 模具改一次的钱 ≈ 几十万到百万，远超软件许可；钱在模具环节，产品就必须"少改模"    |
| Q2  | **谁是签字人，他怕什么？**                         | "谁负责采购"     | 签字人怕召回、怕审计、怕背锅；买不买由"怕"决定，不由"快"决定             |
| Q3  | **哪个决策允许错一次？**                          | "客户需不需要 AI" | 致命决策（结温超限、热失控）永远不给 AI；只有"方案比选"能进             |
| Q4  | **客户的验证成本是多少？**                         | "客户预算多少"    | 验证一次（样件+台架+人工）若 5 万，则"少做两轮"值 10 万——这才是定价的分母  |
| Q5  | **供应链的"免费服务"是不是真对手？**                   | 只盯 Ansys/云道 | 铝挤厂、压铸厂、TIM 厂、风扇厂常免费出热仿真做配套，**价格=0**，是最凶的替代品 |

⭐ **这五个问题的答案，构成后面 24 个动作的骨架。** 调研报告若答不出这五个，查再多数据也是浅的。

## 2. 任务一：顶尖专家会做、而你没要求的事（24 项）

> 分四组：**A 界定问题**（6）→ **B 取证**（6）→ **C 分析**（6）→ **D 交付**（6）。
> 每项都写"不做会得出什么错误结论"——这是判断一件事值不值得做的唯一标准。

### A. 界定问题：把"散热"拆到能被决策的粒度（6 项）

| #      | 专家动作                                | 不做会得出什么错误结论                                                                  | 具体怎么做（可执行判据）                                                                                                                              |
| ------ | ----------------------------------- | ---------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| **A1** | ⭐⭐ **按"物理机制 × 决策类型"二维切分**，而不是按客户行业切 | 会把"车灯厂"当一个市场。实际车灯里至少有 3 类完全不同的热问题：LED 结温/光衰、灯罩起雾凝露、配光镜热变形——**预算科目、判据、工具全不同** | 机制维 9 族：自然对流 / 强迫风冷 / 液冷冷板 / 相变（热管·VC·均温板）/ 辐射 / TIM 界面 / 热电 / 微通道 / 热-结构耦合（翘曲）；决策维 4 类：概念比选 / 详细校核 / 失效归因 / 工艺寻优。**画 9×4 矩阵，每格标"我们做不做"** |
| **A2** | ⭐⭐ **给决策做"可翻转性分级"**                 | 会得出"客户需要更准的模型"，而真问题是"客户只允许某几类决策被自动化"                                         | 三级：**致命**（安全/法规：结温超限、热失控、起火）→ 永不用 AI；**昂贵**（模具/召回/认证）→ 只在有验证闭环时用；**可承受**（方案比选、初筛）→ 可全自动。判据 = 错一次的代价 ÷ 验证一次的成本，**比值 >3 才允许自动化**            |
| **A3** | ⭐ **失效模式驱动，而不是温度场驱动**               | 会做出一份"温度误差 1.2℃"的报告，而客户关心的是"第 3 年光衰是否超标"                                     | 列该细分 Top10 失效：光衰、色漂、焊点热疲劳、TIM 泵出/干涸、翘曲、凝露、热失控、降频、噪声、积尘。**每个失效挂一个客户损失金额与判据标准号**（如 AEC-Q102、JESD51 系列）                                      |
| **A4** | ⭐⭐ **复原签字链与"恐惧清单"**                 | 会以为搞定工程师就搞定客户，实际卡在质量部/项目经理                                                   | 画出：热设计工程师 → 结构主管 → 可靠性/质量 → 项目经理 → 客户 SQE/主机厂。**逐人写"他最怕什么"**（召回、8D、审计、背锅、延期考核）与"他要什么文件才敢签"                                                |
| **A5** | ⭐ **预算科目考古**                        | 会以为"有需求就会买"，实际是"这笔钱没有科目，就走不了流程"                                              | 查明客户把这笔支出记在哪：研发费用 / 模具费 / 试验费 / 信息化 / 技改 / 首台套 / 质量成本。**科目决定金额上限、审批层级、能否资本化**                                                             |
| **A6** | ⭐⭐ **替代品全景，必须包含"供应链免费服务"**          | 会把竞品列成 Ansys/云道/天洑，漏掉真正让客户不花钱的那一类                                            | 六类替代：①Excel+热阻网络（客户自建）②铝挤/压铸/TIM/风扇厂**免费配套仿真**（价格 0，最凶）③厂商学生版/免费版 ④外包按项目（数千到数万元）⑤客户总部/集团研究院统一工具 ⑥"先不上，靠加余量设计"（最常见的 no-decision）           |

### B. 取证：拿到别人拿不到的东西（6 项）

| #      | 专家动作                     | 不做会得出什么错误结论                                             | 具体怎么做                                                                                                   |
| ------ | ------------------------ | ------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| **B1** | ⭐⭐ **先做样本设计，再谈"行业"**     | 62 家清单会被当成"市场"，实际是"名单"；头部 5 家代表不了 60 家                  | 四维分层：体量（>50 亿/10–50 亿/<10 亿）× 热业务占比（主/次）× **是否代工**（自有品牌/ODM）× 是否上市。每格 ≥3 家，约 18 格；**代工格必须单独看**，因为预算结构不同 |
| **B2** | ⭐⭐ **JD 词频做"工具链份额表"**    | 会沿用清单里"是否上 AI：否"的二手判断——已知反例：奇鋐"集团有完整散热与机构模拟软件"          | 抓 200+ 条"热设计/热仿真/热管理"JD，统计出现的软件名与版本、是否要求会写脚本、是否要求"热阻网络/风道/结温"。**客户自己写的招聘要求，就是他真实在用的工具链**                |
| **B3** | ⭐ **读招标的"技术要求"段，不读中标金额** | 会得出"这个市场 300 万级"的规模结论，却不知道客户要求"仿真+试验对比报告"——**这正是我们的门槛** | 抓近 24 个月"散热/热设计/热仿真/热平衡"招标，摘条款原文：结温限值、热阻限值、是否要求试验对标、是否要求国产化/信创、交付期。**做成术语指纹表**                          |
| **B4** | ⭐⭐ **用召回与诉讼证明"需求真实存在"**  | 会把"客户说很重要"当需求；实际口头需求占 90%，能证实的极少                        | 市场监管总局缺陷产品召回公告 + NHTSA recall + 裁判文书网质量纠纷 + 客户 8D 报告（脱敏）。**每一条热相关召回，都是一次真实的失效成本**                       |
| **B5** | ⭐⭐ **把验证成本问出来**          | 会按"竞品报价"定价，而不是按"客户省下的钱"定价                               | 问清四价：铝挤/压铸模具费、单件样件费、热循环/温冲台架小时费、第三方热测试（热阻/红外）单次费。**这四个数决定我们的价格上限**                                      |
| **B6** | ⭐ **客户现场"三个十五分钟"**       | 会一直停留在"访谈说什么"，看不到"他们实际怎么做"                              | 15 分钟看他的 Excel（公式与假设）、15 分钟看他的报告模板（章节=签字要求）、15 分钟看最近一件热失效件（实物+失效分析）                                     |

### C. 分析：把素材变成判断（6 项）

| #      | 专家动作                        | 不做会得出什么错误结论                          | 具体怎么做                                                                                                       |
| ------ | --------------------------- | ------------------------------------ | ----------------------------------------------------------------------------------------------------------- |
| **C1** | ⭐⭐ **用验证成本反推支付意愿**          | 会得出"客户预算有限，卖不动"，而真问题是"我们的定价没对上他省下的钱" | WTP ≈ 每年减少的迭代轮数 ×（样件+台架+人工+延期损失）× 折扣（假想意愿打 ~21% 折）。**算出区间，不给点估计**                                           |
| **C2** | ⭐ **把"加速"翻译成钱（时间价值）**       | 会一直讲"快 5–10 倍"，客户无感                  | 晚发现一个热问题一个月的代价：模具改一次 + 试产延期 + 认证重排。**用客户自己的项目周期算，不用我们的 benchmark**                                          |
| **C3** | ⭐⭐ **池子三算法互校**              | 会拿一个 TAM 数字当结论，被问一句就塌                | ①自上而下：散热件产值 × 研发费用率 ②自下而上：样本客户 × 单客户年支出 ③利润池：钱在模具/样件/试验/软件各占多少。**三者差 >100% 说明口径错，差 <30% 才可进正文**             |
| **C4** | ⭐ **单位经济与交付上限**             | 会做出"三年 100 家客户"的规划，而人力只够 10 家        | FDE 数 × 可交付人天 × 单价 = 收入上限；单客户毛利；CAC 必须含**陪跑 3–6 个月**（否则低估 2–3 倍）                                            |
| **C5** | ⭐ **国外不是"市场多大"，是"卖法能不能迁移"** | 会得出"国外有 nTop，所以国内也会有"，忽略预算科目差异       | 四样本拆卖法：nTop（**按引擎授权**，非席位）、SimScale（订阅 + core-hour）、Altair（席位 + 顾问服务）、Ansys（席位 + HPC）。**逐个问：中国客户这笔钱记哪个科目？** |
| **C6** | ⭐⭐ **红队自攻 + 预注册**           | 会做出一份"怎么看都对"的报告，因为它没有被设计成可被推翻        | 先写"最可能被怎么反驳"（见 §6），再把核心判断写成 H1–H4，**每条带否证条件与观察窗口**；结论四档：KILL / PIVOT / INSUFFICIENT / BUILD                 |

### D. 交付：让判断能被使用（6 项）

| #      | 专家动作                | 不做会得出什么错误结论                            | 具体怎么做                                                                    |
| ------ | ------------------- | -------------------------------------- | ------------------------------------------------------------------------ |
| **D1** | ⭐⭐ **证据台账**（不是参考文献） | 会出现"某报告说""据说"，一追问就崩                    | 每条 claim 一行：结论 / 证据形态 / 来源链接 / 等级（🅐公开可复核 🅑需授权 🅒仅访谈）/ 抓取日期 / 复核人       |
| **D2** | ⭐ **未核实清单单列**       | 会把推测混进结论，事后无法区分"当时不知道"与"当时编的"          | 单列"今天核不了的 4 项"（见 §5.3），写清"需要什么才能核"                                       |
| **D3** | ⭐ **决策请求页，不是结论页**   | 会讲成"信息汇报"，林总听完只能说"再看看"                 | 一页写：请他批什么（做/不做哪个子市场、卖什么形态、押哪个实验）、不批的后果、他需要给的资源                           |
| **D4** | ⭐ **客户黑话词典**        | 会用我们的词（"物理 AI""代理模型"）去问客户，客户听不懂，回答全是客套 | 建对照表：客户说"温升/结温/热阻/降额/泵出/翘曲/余量"→ 我们的"边界条件/材料/收敛/不确定度"。**问客户用他的词，写报告用标准词** |
| **D5** | ⭐ **反定位清单（不做什么）写死** | 会在调研中被"看起来更大的市场"带跑，最后做成四不像             | 明写：不做芯片级、不做设备级、不做系统级、不做通用多物理场求解器、不与云道争"电子散热第一"、不承诺"替代 Flotherm"          |
| **D6** | ⭐ **复盘机制**          | 调研结论对错永远不知道，下次还这么干                     | 90 天后回看：哪条结论被事实推翻、哪条被验证；**把"被推翻"写进下一版的第一页**                              |

## 3. 任务二：最原始的素材（按"离真相的距离"分四环）

> 判断标准：**能不能追到"谁、在什么场合、以什么身份、留下了什么原始痕迹"**。
> 券商报告、行业白皮书、新闻稿、AI 摘要——都不是一手，只能当**线索**。

### 3.1 四环结构

```
环 1 物理世界（最硬）  图纸·BOM·样件·热像·温升曲线·P-Q 曲线·失效件
环 2 组织内部（很硬）  JD·工艺文件·DFM/试模报告·8D·预算表·报告模板·会议纪要
环 3 交易与监管（硬）  招标条款·合同·发票·验收单·召回公告·判决书·专利·标准草案
环 4 公开未加工（较硬）年报附注·10-K risk factors·代理商价目·云市场 listing·论文 supplementary·开源数据集·海关编码
```

### 3.2 环 1：物理世界（客户不会主动给，但最有说服力）

| 素材 | 它证明什么 | 怎么拿 | 等级 |
|---|---|---|---|
| **散热件图纸/3D（脱敏）** | 结构复杂度、材料、壁厚、是否有拓扑优化空间 | 客户工程师现场 | 🅒 |
| **BOM 与 TIM 型号** | 材料成本结构、导热界面方案 | 客户采购/BOM 表 | 🅒 |
| **热电偶布点图 + 温升曲线 CSV** | 真实边界条件与热点位置（比任何报告都准） | 客户试验室 | 🅒 |
| **红外热像图（原始文件）** | 温度分布形态，可反推对流/辐射占比 | 客户试验室 | 🅒 |
| **风洞/风机的 P-Q 曲线** | 系统阻抗与工作点，决定风量是否够 | 风扇厂规格书 | 🅐 |
| **热阻测试报告（JESD51 系列）** | 结壳热阻/结板热阻，是芯片级到板级的桥 | 器件厂/第三方实验室 | 🅑 |
| **失效件实物 + 失效分析（FA）** | 失效模式与根因，是需求的源头 | 客户质量部 | 🅒 |
| **模具试模报告 / 翘曲测量** | 制造约束的真实边界（拔模、缩水、变形） | 模具厂/客户工艺 | 🅒 |

### 3.3 环 2：组织内部（最容易被忽略，信息密度最高）

| 素材 | 它证明什么 | 怎么拿 |
|---|---|---|
| **热设计/热仿真 JD 原文** | 真实工具链、团队规模、是否要求写脚本 | 招聘网站（可批量） |
| **内部报告模板（章节结构）** | 签字要求：要哪几章、要不要试验对比、要不要 GCI | 客户给的样例（脱敏） |
| **DFM / 工艺评审记录** | 设计被制造约束打回的真实原因 | 客户工艺部 |
| **8D / 客诉单** | 失效成本与响应流程（谁被追责） | 客户质量部（脱敏） |
| **年度预算表（研发/试验科目）** | 钱有没有科目、上限多少 | 客户财务/研发管理 |
| **项目周会纪要（脱敏）** | 真实卡点在哪一环（常是样件与试验排队） | 客户项目经理 |
| **供应商报价单与交期** | 成本与时长的真实分布 | 客户采购或供应商 |

### 3.4 环 3：交易与监管（可公开复核，最适合写进报告）

| 素材 | 它证明什么 | 具体渠道 |
|---|---|---|
| **招标文件"技术要求"原文** | 客户验收判据（结温/热阻/是否要求试验对标/是否要求国产化） | 中国政府采购网、各省公共资源交易中心、招标网 |

### 3.5 环 4：公开但未被加工（便宜、可复核，但要会挑）

### 3.6 什么不算一手（直接删）

- 券商研报里的 TAM（口径不可追，常互相抄）；
- 行业白皮书的份额图（无方法论说明）；
- 新闻稿里的"某企业已应用于 X"（无客户名、无数字）；
- 二手转述的"某厂说预算有限"（无原话、无身份）；
- AI 生成的摘要与"综合判断"（不可复核）。

## 4. 任务三：具体方法、手段与工具

> 六类，每类给：**用哪个、为什么用它、输出什么、坑在哪**。

### 4.1 需求发现（把"想要"变成"会买"）

| 方法 | 用它回答什么 | 工具 | 坑 |
|---|---|---|---|
| **JTBD 访谈**（Jobs to be Done） | 客户"雇"我们的产品去完成什么任务 | 访谈提纲 + 录音转写 | 问成"你想要什么功能"就失效，要问"上一次你怎么解决的" |
| **关键事件法**（Critical Incident） | 最近一次热失效/延期是怎么发生的 | 5 Whys + 时间线 | 只访一个人会得到"英雄叙事" |
| **Kano** | 哪些是必须型（没有就否决）、哪些是无差异型 | 问卷（每细分 ≥30 份） | ⚠️ "AI 能力"很可能是**无差异型**，别默认是兴奋型 |
| **购买中心分析** | 谁发起、谁评估、谁签字、谁付钱 | 角色表（12 角色） | 只访使用者＝无法证伪伪需求 |
| **决策旅程图** | 从"发现问题"到"签合同"经过几道闸 | 流程图 + 每闸的判据 | 漏掉"预算科目"这一闸，流程必卡 |

### 4.2 定量与定价（把"愿意付"变成"多少钱"）

| 方法 | 用它回答什么 | 工具 | 坑 |
|---|---|---|---|
| **Van Westendorp PSM** | 价格区间（太便宜/合理/太贵） | 问卷 ≥100 份/细分 | 假想意愿高估 ~21%，必须打折 |
| **Gabor-Granger** | 不同价位购买概率 | 问卷 | 样本偏差（只访熟人） |
| **CBC Conjoint** | 客户在"精度/速度/价格/服务"间怎么权衡 | 专业软件/问卷平台 | 需 200–300 份，成本高 |
| **MaxDiff** | 功能优先级排序 | 问卷 | 不能替代 Kano |
| **价值定价（以验证成本为分母）** | 我们该定多少钱 | Excel 模型 + 客户项目数据 | 用"竞品报价"定价 → 永远卖不贵 |

### 4.3 市场测算（三个算法互校）

| 方法 | 用它回答什么 | 工具 | 坑 |
|---|---|---|---|
| **自上而下**（产值×研发率） | 池子上限 | 统计年鉴、行业协会、上市公司合计 | 研发率口径差异极大 |
| **自下而上**（样本×单客户支出） | 池子下限 | 62 家分层表 | 样本偏差会被放大 |
| **利润池分析** | 钱在开发流程哪一环 | 价值链拆解 + 访谈 | 只算软件会漏掉模具/试验的大头 |
| **单位经济模型** | 我们能吃多少 | Excel：FDE 数×人天×单价 | 忘算陪跑期 → CAC 低估 2–3 倍 |

### 4.4 竞争情报（合规前提下的硬手段）

| 方法 | 用它回答什么 | 工具 | 坑 |
|---|---|---|---|
| **Battlecard（11 格）** | 遇到这个对手怎么打 | CRM 里的卡片（不是 Wiki） | 6 个月不复核即作废 |
| **Win/Loss 访谈** | 为什么赢/为什么输 | 访谈脚本（赢单 30 天内、输单 30–60 天） | 由原 deal owner 访＝听不到真话 |
| **招标术语指纹** | 客户已经被谁的术语"洗过" | 关键词表 + 全文检索 | 只看金额会漏掉技术倾向 |
| **专利地图** | 谁在布什么、布到哪 | CNIPA/Google Patents + 引证分析 | 只看数量不看权利要求＝没看懂 |
| **感知图（MDS）** | 客户心里我们排第几 | 访谈打分（≥50 人）+ 多维标度 | 轴选错＝"右上角空无一物"的假机会 |

### 4.5 技术验证（让"我们的东西行不行"变成数字）

| 方法 | 用它回答什么 | 工具 | 坑 |
|---|---|---|---|
| **热阻网络一维建模**（Foster/Cauer） | 快速估算结温，作为 CFD 的 sanity check | Excel / Python | 只适用一维热流路径，别外推 |
| **P-Q 曲线 × 系统阻抗** | 风量工作点、是否够冷 | 风扇规格书 + 阻抗曲线 | 只报温度不报压降＝把多目标问题偷换成单标量 |
| **CFD + GCI** | 网格无关性与数值不确定度 | Flotherm / Icepak / 6SigmaET / OpenFOAM | GCI 必须 ≥3 级网格、细化比 ≈1.5、**h 不能用单元数相除** |
| **DOE（试验设计）** | 哪些参数真的影响结果 | optiSlang / Dakota / pyDOE | 参数 ≲20 且拓扑不变，否则参数化失效 |
| **敏感性分析（Sobol）** | 哪个输入贡献最大 | SALib | 只做局部敏感性＝结论不可外推 |
| **代理模型 + 不确定性量化** | 外推能不能信 | FNO/POD/GP + conformal prediction（MAPIE） | ⚠️ 外推失效是结构性缺陷；必须给"拒绝服务区" |
| **NAFEMS 基准回归** | 我们算得准不准（第三方可复核） | CFD R0123、静力 P07、assess26-01 | 只跑"通过"的算例＝自欺 |

### 4.6 数据工程（让结论可复现）

| 方法 | 用途 | 工具 |
|---|---|---|
| 批量抓取 JD/招标/新闻 | 工具链份额、术语指纹 | Python（requests/Playwright）、八爪鱼 |
| 中文分词 + TF-IDF | 词频与主题 | jieba + scikit-learn |
| 实体对齐 | 集团/子公司/品牌归一 | Excel 映射表 + 人工复核 |
| 结构化台账 | 62 家字段统一 | 飞书多维表 / Airtable / Excel |
| 版本与可复现 | 换人能跑出同一结论 | Git + `scripts/` + 数据快照 |

### 4.7 ⚠️ 专家**不会**用的工具（这些是浅层调研的典型标志）

- 直接问大模型"中国散热市场规模"（口径不可追）；
- 引用券商研报的 TAM 当结论（互相抄，差 4 倍）；
- 只做 feature matrix 功能对比（客户买的是能签字的结果，不是功能）；

- 用"AI 能力"当差异化轴（Kano 无差异型，客户不为此付钱）。

## 5. 任务四：独立于你、我之外的验证

> 目标不是"我信"，是**"第三方按链接点开就能自己判断"**。
> 分六层，从物理到交易。

### 5.1 六层验证

| 层 | 手段 | 能证明什么 | 强度 |
|---|---|---|---|
| **L0 物理/解析** | 一维导热解析解、翅片效率、Hertz 接触、能量守恒（输入功率=散热+储热） | 结果是否违反物理 | ★★★★★（不可辩驳） |
| **L1 标准与基准** | JESD51 系列（结温/热阻）、AEC-Q102（车用 LED）、ISO 16750-4（车载气候）、IEC 60068-2-14（温冲）、NAFEMS（CFD R0123 / P07 / assess26-01）、GCI 报告 | 方法与判据是否合规 | ★★★★★ |
| **L2 第三方检测** | CNAS 认可实验室出具的热阻/温升/热像报告（广电计量、赛宝、SGS、TÜV 等） | 数值是否在第三方台架上成立 | ★★★★☆ |
| **L3 客户盲测回测** ⭐ | 拿客户**过去 3–6 个月已完成的 3 个项目**，隐藏结果，我们先预测，再对比；客户工程师签字确认 | 我们的方法在**真实项目**上是否有效 | ★★★★★（最强的商业验证） |
| **L4 交易与监管** | 合同、发票、验收单、召回公告、判决书、中标公示 | 是否真的有人付钱、是否真的有失效 | ★★★★☆（付费=硬证据） |
| **L5 可复现** | 数据快照 + 脚本 + 双人复核 + "链接可点开率 ≥95%" | 结论是否可被他人重跑 | ★★★☆☆（保证不自欺） |

### 5.2 怎么设计一次"让第三方无法反驳"的验证（四步）

| 步 | 动作 | 产出 |
|---|---|---|
| 1 | **预注册**：把假设、判据、样本、否证条件在实验前写死并落盘（带日期与签字） | 一页 pre-registration |

| 4 | **公开链接**：所有引用数据附原始出处链接与抓取日期 | 证据台账 |

### 5.3 今天注定核不了的（写进报告，别硬编）

## 9. 附录

### 9.1 客户黑话 → 标准术语

| 客户说 | 标准说法 | 为什么重要 |
|---|---|---|
| 温升 | 相对于环境的温度增量（ΔT） | 边界条件不同，数不可比 |
| 结温 | 器件结温 Tj（JESD51 测法） | 与壳温/板温差 10–30℃，混用会错一个量级判断 |
| 热阻 | 结-壳 Rθjc / 结-板 Rθjb / 结-环境 Rθja | 三者不可互换，报告必须写清是哪一个 |
| 降额 | 温度降额曲线（derating） | 决定"能不能用"而不只是"热不热" |
| 余量 | 设计裕度（safety margin） | 客户常以"加余量"替代仿真，这是最强的替代品 |
| 泵出 | TIM pump-out（热循环导致界面材料迁移） | 长期可靠性问题，静态仿真看不见 |
| 翘曲 | warpage（热-结构耦合变形） | 需要热-力耦合，纯热分析答不了 |

### 9.2 证据等级定义

- 🅐 **公开可复核**：有 URL、可被任何人点开验证；
- 🅑 **需授权/付费**：报告原文、标准正文、数据库；
- 🅒 **仅访谈**：客户口头或脱敏材料，需注明访谈时间、对象角色、是否录音。
