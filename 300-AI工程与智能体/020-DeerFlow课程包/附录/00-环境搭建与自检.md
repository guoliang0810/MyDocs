# 环境搭建与自检（建议 Day01 课前完成）

## 必备软件
- Git
- Python 3.11+（建议用虚拟环境）
- Docker Desktop（可选：如果做容器沙箱扩展）
- VS Code 或 Trae（任意 IDE）

---

## 建议的 Python 虚拟环境（示例）
你可以用 `venv` 或 `conda`，任选其一即可。

### venv（推荐给初学者）
```bash
python -m venv .venv
.\.venv\Scripts\activate
python -m pip install -U pip
```

---

## 自检清单（出现问题先在这里卡住）
### 1) Python 是否可用
```bash
python --version
```

### 2) pip 是否可用
```bash
python -m pip --version
```

### 3) Docker（可选）
```bash
docker version
docker ps
```

---

## 学习用项目建议结构（你最终会做出来的 Mini-DeerFlow）
你会逐步搭建类似结构（不要求一开始就长这样）：
```text
mini-deerflow/
  src/
    gateway/
    agent_runtime/
    tools/
    sandbox/
    subagents/
    memory/
    config/
  artifacts/
  uploads/
  workspace/
  tests/ or scripts/
  pyproject.toml
  README.md
```
