# 1个月（21天）从零到“能手搓类 DeerFlow 智能体系统”的课程课纲

## 课程目标（对初学者的可达成版本）
完成本课程后，学生能够从零实现并解释一个“Mini-DeerFlow”级别的智能体工程，具备下列能力：
- 用 LangGraph（或等价的状态机/编排思路）搭建多步骤 Agent 流程
- 设计可扩展的 Tool/Skill 体系（含参数校验、权限边界、错误治理）
- 设计 Sandbox 抽象并提供至少一种 Provider（本地隔离或容器隔离）
- 设计 Middleware/Hook 链处理横切关注点（上传、线程目录、总结、标题、记忆等）
- 设计 Subagent 调度（并发、限流、超时、结果聚合、可观测事件）
- 设计 Memory（短期上下文压缩 + 长期事实存储与注入）
- 提供一个最小可用的 HTTP API（线程、消息、工具/技能列表、文件/产物）
- 具备“读源码学架构”的方法：能拆解 DeerFlow 的关键模块并复刻其骨架

说明：DeerFlow 本体工程量很大（后端 + 前端 + Docker/Nginx + 多种社区工具与配置系统）。本课程以“可复刻架构要点 + 能跑通关键能力”为目标，最终产物在架构上对齐 DeerFlow 的核心理念，但规模更适合 1 个月初学者完成。

## 能力地图（从基础到架构师）
### A. 基础工程能力
- Python 基础语法、类型标注、异常处理、结构化日志
- HTTP/JSON、FastAPI 路由、依赖注入、错误码与统一响应
- Git 基础、项目结构、配置与环境变量

### B. Agent 编排能力
- State（状态）、Node（节点）、Edge（边）、循环、终止条件
- Tool calling（工具调用）协议与返回消息格式
- 流程拆分：计划→执行→检查→反思→产物

### C. 运行时系统能力
- Middleware 链：输入增强、输出后处理、权限/限流、上下文治理
- Sandbox：抽象接口、路径虚拟化、执行隔离、资源限制
- Subagent：并发、队列、超时、结果一致性、事件流

### D. 可扩展与可维护能力
- Skills：发现、加载、冲突治理、命名规范、能力注入
- 配置：分层覆盖（默认→环境→请求）、校验、热更新策略
- 测试：单测/集成、接口契约、回归策略

## 课程产物（你最后要“手搓出来”的东西）
### 最终项目：Mini-DeerFlow（后端为主，可选简单前端）
必做模块：
- `gateway`：FastAPI API 网关（threads/messages、skills、uploads、artifacts）
- `agent_runtime`：LangGraph Lead Agent + 可插拔 middleware 链
- `tools`：内置工具（read/write/list/exec 等）+ 最少 3 个业务工具（检索/总结/报告）
- `sandbox`：抽象 + LocalSandboxProvider（必要），可选 DockerSandboxProvider
- `memory`：JSON 文件存储（必要），可选向量检索/结构化抽取
- `subagents`：任务委派执行器（必要），含并发限制与超时
- `config`：统一配置加载与校验（必要）

验收标准（毕业答辩脚本）：
- 演示一次“多步研究任务”：分解→工具调用→生成产物（markdown）→保存→可下载
- 演示一次“子任务并行”：3 个子任务并发完成并聚合总结
- 演示一次“长期记忆”：用户偏好/事实写入后能在新对话被注入
- 演示一次“沙箱边界”：路径穿越尝试被拒绝，危险命令被拦截或隔离

## 21天总进度表（每天 4×45min）
每天的详细“课件 + 教案 + 学生材料 + 作业”在 `../每日/DayXX.md`

### 第1周：从零到可跑通的单 Agent（Day01–Day05）
- Day01：工程化入门、HTTP/JSON、项目骨架、最小 FastAPI
- Day02：LLM 调用与消息格式、Prompt 结构、可观测日志
- Day03：LangGraph/状态机思维、最小 Lead Agent 跑通
- Day04：Tool calling 与工具注册、错误处理、schema 校验
- Day05：产物系统（artifacts）与文件读写边界（Local sandbox）

### 第2周：系统化能力（Day06–Day10）
- Day06：Middleware 链设计与实现（输入/输出拦截）
- Day07：上传与线程工作目录（workspace/outputs/uploads）
- Day08：Context 治理：摘要/trim/keep 策略（类 summarization）
- Day09：长短期记忆：抽取→存储→注入（类 memory middleware）
- Day10：API 设计：threads、history、artifacts、skills 列表

### 第3周：复杂度提升（Day11–Day15）
- Day11：Subagent 执行器：并发、超时、取消、聚合
- Day12：任务分解策略：planner/executor/checker 模式
- Day13：Sandbox 扩展：命令执行白名单、资源限制策略
- Day14：Skills 系统：发现/加载/命名冲突/能力注入
- Day15：测试与回归：契约测试、冒烟测试、关键路径覆盖

### 第4周：对齐 DeerFlow 的“架构味道”（Day16–Day21）
- Day16：路由与网关分层：runtime vs gateway，模块边界
- Day17：可观测性：trace id、事件流、SSE/轮询模型
- Day18：安全：输入校验、路径虚拟化、工具权限、密钥管理
- Day19：性能与成本：缓存、并发、token 策略、分层模型选择
- Day20：源码对照读 DeerFlow：middleware、subagent、sandbox、skills、memory
- Day21：毕业项目整合与答辩：全链路演示、架构图、故障演练
