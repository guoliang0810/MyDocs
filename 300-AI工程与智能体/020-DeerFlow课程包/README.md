# 100-AI-Agent-工程：1个月（21天）Mini-DeerFlow 课程包

## 使用方式（每天直接照着上课）
- 打开 `每日/DayXX.md`，按 4 节课顺序授课（每节 45 分钟）
- 每天末尾有“当天作业（必做/选做）+ 提交物 + 自测”
- 老师用：每个 Day 文件里都有“老师教案”段落
- 学生用：每个 Day 文件里都有“学生材料”段落
