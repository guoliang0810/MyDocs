## 第1节（45min）：Agent 成本从哪来
### 课件
1. 大头：模型调用次数 × token
2. 次要：工具调用（网络/执行）、存储 IO
3. 性能/成本指标：
   - 每次请求耗时
   - 平均 token
   - 工具成功率/超时率

## 第2节（45min）：缓存策略（先做安全的）
### 课件
1. 适合缓存的：
   - skills 列表（扫描结果）
   - 工具元数据（registry）
   - 只读配置
2. 不适合缓存的：
   - 带用户隐私的内容
   - 具有副作用的写操作

### 课堂跟做
实现 2 个缓存点：
- skills loader 的扫描结果（按 mtime 失效）
- memory store 的读取结果（按 mtime 或 ttl 失效）

---

## 第3节（45min）：token 策略与降级
### 课件
1. token 管理三板斧：
   - keep：系统约束与事实
   - trim：丢过程噪音
   - summarize：压缩历史
2. 降级策略：
   - 摘要失败 → 裁剪
   - 工具超时 → 返回缺口说明

### 课堂跟做
让你的 summarization 支持：
- 最大轮数/最大长度
- 摘要失败的降级处理（仍可继续对话）

---

## 第4节（45min）：分层模型（cheap model 做脏活累活）
### 课件
1. 便宜模型适合：
   - 摘要
   - 结构化抽取（memory extractor）
   - 标题生成（可选）
2. 贵模型适合：
   - 复杂推理
   - 多工具协作
   - 最终报告生成

### 课堂跟做
在 config 中加入：
- `models.primary`
- `models.cheap`

并把 summarization/memory_extractor 绑定到 cheap model（若存在）。
