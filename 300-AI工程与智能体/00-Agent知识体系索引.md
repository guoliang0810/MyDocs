## 🎓 DeerFlow 课程包 → 可直接改造为客户赋能课程

> 这是本库最被低估的资产。它的价值不在"AI 知识"，
> 而在**"如何把一个重型、不可靠、不可解释的物理计算引擎安全地包进 Agent"的完整操作手册**。

| 课程包结构 | 对应物理 AI 场景 |
|---|---|
| Sandbox 抽象 + 命令白名单 + 资源限制 + 路径虚拟化（Day05/13） | **把 CAE 求解器当作受限外部进程**——白名单化可执行求解器、限制 CPU/内存/时长、隔离客户模型目录 |
| Planner / Executor / Checker 三段式（Day12） | 建模 → 求解 → **校核**（收敛性、网格无关性、结果合理性） |
| Artifacts 产物系统（Day05） | 仿真报告、云图、参数化模型、JSON 结果集作为**可下载产物**——"对话是过程，产物才是交付" |
| Subagent 并发 + 超时 + 聚合（Day11） | 参数扫描 / 多工况批量仿真并行、作业提交编排 |
| 上下文治理（Day08） | 长会话下的历史仿真记录、参数表、失败算例的压缩 |
| 可观测性 trace + 事件流（Day17） | 算例级追踪（哪次求解、什么网格、多少步、是否收敛）——客户现场复现与审计 |
| 权限 scope + 输入校验 + 红线清单（Day18） | 客户数据不出域、模型文件只读、许可证校验、密钥托管 |
| 成本/分层模型（Day19） | 方案设计用强模型，报告润色/参数抽取用小模型 |
| Skills 系统（Day14） | 把"复材机翼求解流程""骨科术前规划流程"封装成**可复用技能包** |

### 教学设计资产（对客户赋能极稀缺）

- `课程资料/01-教师总教案.md` —— 45min 时间盒配方、4 节课角色分工、卡点话术
- `附录/01-评分量表与提交规范.md` —— 每日 10 分制（能跑 4 / 功能 2 / 边界 2 / 可观测 1 / 可复现 1）
- Day21 故障演练 + 答辩脚本 —— **架构师常问三问：为什么这么拆 / 边界在哪 / 降级策略**

> ⭐ **"你的降级策略是什么"正是物理 AI 交付现场最常被问的问题。**
