# 智泊AI大模型应用开发实战 - 学习路线

> [!INFO] 课程说明
> 本学习路径基于 **智泊AI人工智能研究院 6.0.0** 课程体系整理，旨在帮助开发者从传统开发转型为 AI Agent 全栈开发者。
> 重点涵盖：Prompt Engineering、RAG 检索增强生成、LangChain 开发框架及 Agent 智能体实战。

## 📅 学习进度规划

### 第一阶段：大模型基础与 Prompt 工程 (Foundation)
- [ ] **[[01-LLM核心原理]]**: AI 1.0 vs 2.0、Transformer 架构通俗解析、预训练与微调 (SFT/RLHF)。
- [ ] **[[02-Prompt工程进阶]]**: 结构化提示词、CoT 思维链、提示词攻击与防范、自动化 Prompt 优化。
- [ ] **实战项目**:
    - [ ] SQL 代码生成助手
    - [ ] 小红书爆款文案生成器
    - [ ] 个人辅导 AI 助手

### 第二阶段：RAG 检索增强生成 (RAG)
- [ ] **[[01-RAG架构与实战]]**: RAG 核心流程（索引/检索/生成）、文档切分策略 (Chunking)。
- [ ] **向量数据库**: Vector DB 原理、Embedding 模型选择、Faiss/Milvus/Pinecone 实战。
- [ ] **进阶 RAG**: 混合检索 (Hybrid Search)、重排序 (Rerank)、Query Rewrite。
- [ ] **实战项目**:
    - [ ] 企业级私有知识库问答系统
    - [ ] 垂直领域（医疗/法律）智能顾问

### 第三阶段：LangChain 与 Agent 开发 (Application)
- [ ] **[[01-LangChain核心组件]]**: Chain、PromptTemplate、OutputParser、Memory。
- [ ] **LCEL**: LangChain Expression Language 声明式编程。
- [ ] **AI Agent**: ReAct 框架、Tool Use (Function Calling)、Multi-Agent 协作。
- [ ] **实战项目**:
    - [ ] 自动化数据分析 Agent
    - [ ] 能够操作 API 的智能助理

## 📚 推荐资源
- **框架**: [LangChain](https://python.langchain.com/), [LlamaIndex](https://www.llamaindex.ai/)
- **模型**: OpenAI GPT-4, Anthropic Claude 3, DeepSeek-V3 (国产之光)
- **工具**: LangSmith (调试), LangGraph (多智能体)
