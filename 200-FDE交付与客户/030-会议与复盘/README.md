# 会议与复盘

> **会议纪要不是流水账，是决策记录。**
> 判断一场会是否值得开，看散会后能不能填出"决定了什么、没决定什么、下一步谁做什么"。

---

## ⭐ 会议纪要必须回答的四个问题

1. **决定了什么？**（有明确结论的才算决策）
2. **没决定什么？为什么？**（分歧与阻塞点，比结论更有信息量）
3. **下一步谁做什么？**（有责任人和时间）
4. **⭐ 什么回流到产品？**（本次会议的产出，沉淀到 L1–L4 的哪一层）

> 第 4 问是 FDE 的 KPI。答不上来，说明这场会只是走流程。

---

## ⭐ 复盘必须回答的两个问题

1. **哪个工况算不出来？为什么？**（客户和监管方都会问）
2. **哪个可复用资产没有沉淀？卡在哪？**
