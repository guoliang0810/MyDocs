# 客户档案

> **一个客户 = 一份档案。** 档案按 `客户名.md` 命名。
> 新客户接入时，用 [[500-模板与规范/客户档案模板]] 起稿。

---

## 📁 归档规则

| 字段 | 值 |
|---|---|
| 文件名 | `客户名.md`（与公司名一致，便于搜索） |
| 内部代号 | 如有，用代号 |
| 阶段 | 线索 / PoC / 试用 / 正式采购 / 已结束 |
| 归档时机 | 项目结束后**不删除**——它是产品决策的历史依据 |

## ⚠️ 每份档案必须有的三样东西

1. **问题契约** —— 目标量 / 方向 / 约束 / 验收判据
2. **约束台账** —— 载荷、材料、工艺、边界、法规逐条记录
3. **⭐ 回流清单** —— 沉淀到 L1–L4 的资产，这是 FDE 的 KPI
