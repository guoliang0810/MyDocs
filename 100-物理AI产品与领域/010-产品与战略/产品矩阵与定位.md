# 清航飞迈产品矩阵与定位

> 作为产品负责人，这份文档是**所有需求决策的出发点**。
> 判断一个需求该不该做，先看它落在哪一层、是否与产品定位一致。

---

## 一、公司与产品矩阵

清航飞迈（上海）科技软件有限公司，2024 年成立，由**清华大学航天航空学院庄茁院士**牵头创办。
核心团队汇聚清华体系力学、材料、机械、人工智能跨学科骨干，成立初期获数千万元天使轮融资。

产品矩阵为"底层支撑 — 开发赋能 — 场景落地"三层：

| 产品 | 定位 | 目标用户 | 核心价值 |
|---|---|---|---|
| **AICube** | 物理世界引擎（全栈自研 CAE 仿真层） | 仿真工程师、CAE 平台 | 集物理计算、AI 预测、智能优化于一体；**仿真速度提升 80%、部署成本降低 70%**（官方口径） |
| **Solid** | 物理 AI 开发平台 | 开发者、仿真专家、算法工程师 | 深度融合物理模型与神经算子，打通"仿真—训练—推理—优化—验证"全流程 |
| **LoopAxis** | 即用型行业应用平台 | 工程用户（非仿真背景） | 封装标准化行业方案，**无需复杂技术背景**即可落地 |

| 航空航天 | 中国商飞 | C919 大型复材机翼"算不了"难题攻克，**单舱减重 150KG** | AICube + Solid |

## 三、产品定位的三条护城河假设

### 护城河 1：数据血统（provenance），不是算法
NAFEMS 2026 年互操作报告的核心论断：
> "中性文件格式保住数值完整性，却装不下工程意图……没有元数据，仿真结果仍被锁死，
> **缺乏支撑高后果决策所需的血统**。这一风险**在组织采用机器学习策略时被放大**。"

**含义**：AICube 若想在 C919 与骨科落地，优先级应该是**可追溯的数据交换层**（VMAP / CGNS / EXODUS II），
而不是"再做一个更强的模型"。神经算子的可信度瓶颈在数据血统，不在网络结构。

**动作**：加入 VMAP 标准社区（VMAP SC）。既获得 IP 护城河，又进入每一个 CAE 采购的兼容性议程。

### 护城河 2：交付能力，而非功能列表
真实 CAE 采购公告揭示了客户买的是什么：

| 采购标的 | 成交价 | 日期 |
|---|---|---|
| Simulia ABAQUS 2026，1 套 | ¥1,187,500 | 2026-09-22 |
| Ansys 多物理场有限元仿真工具 | ¥4,947,000 | 2025-11-19 |
| 达索 ABAQUS 科研版（5 用户并发） | ¥1,526,000 | 2026-08-13 |
| Abaqus（单一来源） | ¥743,800 | 2026-01-21 |
| 机翼防冰三维流体**国产**仿真软件模块 | 预算 ¥150 万 → ¥1,206,300 | 2026-05-26 |

> 客户采购的不是求解器，是**"能交付、能验收、能过国产化审核、能二次开发"的一整套东西**。
> 典型交付包 = 软件 + 二次开发工具集 + 云化部署 + 标准库配置 + 系统培训 + 文档 + IP 证明文件 + 原厂唯一授权。

**含义**：LoopAxis / Solid 的产品形态应对标"模块 + 交付包"，而非"单个软件"。

### 护城河 3：FDE 的经验回流
Palantir 对 FDE 的原始定义（官方博客）：
> "Dev 的关注点是**一个能力服务多个客户**，而 Delta（FDE）的关注点是**一个客户用上多个能力**。"
> "我们最有价值的产品功能，往往源自一线现场。"

独立数据：982 个在招 FDE 岗位薪资中位数 $188K；**1000 个 JD 中 0% 带销售配额**。

**含义**：FDE 的 KPI 必须包含**回流到产品的比例**。
清航飞迈手上有 C919、美的电机、两家三甲医院三类完全不同的场景——
经验若不回流到 Solid 和 LoopAxis，就只是三个项目；回流了，才是竞品买不到的行业知识资产。

## 四、需求决策的判断框架

一个新需求进来，依次过四道闸：

```
① 落层判定      属于 AICube / Solid / LoopAxis 哪一层？还是跨层？
   ↓
② 复用判定      是否已有可沉淀的资产？（模板 L1 / 参数库 L2 / 求解器插件 L3 / API L4）
   ↓
③ 验证判定      验收标准是什么？能否落到 NAFEMS 基准或 GB/T 33582 章节上？
   ↓
④ 回流判定      这个需求的产品化形态是什么？沉淀到哪一层？
```

四道闸全过才立项。**只过①②不过③的，是定制项目；只过①不过④的，是一次性外包。**

## 五、⭐ 竞争定位的诚实评估（v2 新增，含 CAD 侧）

> **"我们也能在 CAD 里跑仿真"已经不是差异化。**
> 这一节把 CAD-CAE 一体化的真实水位摊开，避免自说自话。

### 5.1 已经被做透的三层

| 层级 | 玩家 | 已经做到什么 |
|---|---|---|
| **L4：同一数据模型、无需导出转换** | 达索 3DEXPERIENCE MODSIM（CATIA+SIMULIA） | 官方："CAD model 与 simulation model 完全同步，**无需导出、转换或清理**"；改几何→仿真自动更新；基于物理的生成式设计与 DOE |
| **L4：同一数据模型** | 西门子 Simcenter Simsolid | "**无需几何简化、无需网格划分**"，直接吃完整 CAD 装配体（含粗糙接触面、间隙、重叠几何）；标准 PC 上秒到分钟出结果 |
| **L3：装配级 FEA 内嵌 CAD** | Onshape Simulation | 浏览器内静力+模态；**装配 mates 自动转仿真运动学**；无需 defeaturing、无需 meshing；结果随装配版本控制 |

> ⭐ **真正做到"无导出 + 无网格 + 装配 mates 直接变运动学 + 结果随版本走"的只有这三家。**

### 5.2 所以真正的差异化只能在这三处

| # | 差异化方向 | 为什么对手没做 |
|---|---|---|
| **1** | ⭐ **AI 代理模型替代多少求解器次数** | SimSolid 是**确定性无网格 FEM**，不是 AI。它替代的是"网格"，不是"物理场求解"。而物理 AI 替代的是**物理场求解本身** |
| **2** | ⭐ **C919 级复材的层合板本构 + 变刚度设计** | 路径已现（CAE2 年会：基于图神经网络的连续板体代理模型、非均质各向异体本构模型、跨尺度协同进化算法）—— SimSolid/Onshape 都不覆盖 |
| **3** | ⭐ **医疗骨科完整物理链路** | CT 分割 → 3D 骨缺损重建 → 术前规划 → 术后受力仿真，这是完整物理链路而非单点工具 |

### 5.3 伪差异化（必须避免的自嗨）

| ❌ 不能当作护城河 | 原因 |
|---|---|
| "支持主流 CAD 格式导入" | STEP 是行业标配；**能做**不构成优势，**做得快/准/不炸**才是 |
| "有 AI 助手" | 2026 年 CAD 厂商全都有（SOLIDWORKS 2026 AI 虚拟伙伴、Autodesk Neural CAD、Onshape） |
| "能在浏览器里跑" | Onshape 已经做了，且免费版可用 |
| "几何深度学习模型" | ⭐ 研究层面领先 ≠ 工业可交付。真实失败模式见 [[CAD与几何工程#六-真实工业交付中的失败模式最重要的一节]]：泛化性、可执行≠正确、能力悬崖、B-rep 多米诺崩塌 |
| "速度快 80%" | 无法给出基准算例、网格规模、精度等效性证明时，这句话是负债不是资产 |

### 5.4 ⭐ 唯一可能真正成立的护城河：几何侧的可信入口

> **这个判断来自一个可复核的事实**：
> CAE 的失败有 80% 源于几何本身有缺陷。
> 而几何缺陷的判官是**确定性的几何内核**，不是人眼、不是标注者、不是相似度阈值。

**因此"把几何入口做可信"是可防守的能力**：
- 内置 healing + defeaturing（不是让客户自己修）
- 入口预检用内核六层验证（可执行 → B-rep 有效 → 水密 → 流形可网格化 → 量守恒 → 拓扑不变量）
- 意图传递（Persistent ID，CAx-IF v1.8）保住装配/材料/基准/PMI 语义

> ⭐ **对手可以很快抄"能导入 STEP"，但很难抄"导入后 10 秒告诉你哪里有问题、并且自动修好"。**
> 这才是 AICube 入口层该建的能力。
