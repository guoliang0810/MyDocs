## 🧭 快速索引：按任务查

### 我要交付一个客户仿真项目
1. [[仿真可信度V-V与标准体系#网格无关性研究 GCI]] — 至少 3 级网格，细化比 ≈1.5，GCI ≤ 5%
2. [[交付验收与报告规范]] — 报告章节须符合 GB/T 33582-2017
3. [[FDE角色与工作标准#PoC 设计]] — PoC 门槛是方法论门槛，不是结果门槛

### 我要评估一个代理模型能不能上
1. [[代理模型与神经算子工程化#交付前必做的十项验证]]
2. 重点看**外推复杂度**（NeU-PINN 的 2-Wasserstein 距离）与**谱误差分解**
3. 是否有 NAFEMS Data Driven Benchmark 的跑通结果？

### 客户质疑"你们比 ANSYS 快 80%"
1. [[100-物理AI产品与领域/030-竞品与市场/竞品与市场情报#宣传数字的证伪清单]]
2. 要求给出：对比基准算例、网格规模、精度等效性证明、硬件配置、是否含网格与后处理时间
3. 提醒：DPW-6 显示即使同一基准同一网格，7 个独立 CFD 码的 CL 仍有 1% 差异，18% 提交为离群值

### 我要写一份行业标准或竞品分析

2. ASME **VVUQ 60.1-2025** 是官方的"计算物理仿真软件选型问卷"，可直接用
3. ASME **VVUQ 70 / 90** 仍在制定中（机器学习算法 V&V / 机身结构）—— **谁先参与谁定义**

### 我在设计 Solid 的 API
