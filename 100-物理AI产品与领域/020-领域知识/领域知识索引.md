## 🧭 快速索引：按任务查

### 我要交付一个客户仿真项目
1. [[CAD与几何工程#一-几何清理healingcae-前处理-60-工时所在]] — 几何是第一道闸，先清理再谈求解器
2. [[CAD与几何工程#四-网格质量阈值表专家会建立的三档基线]] — 建立三档阈值表，只局部加密不合格区
3. [[仿真可信度V-V与标准体系#网格无关性研究 GCI]] — 至少 3 级网格，细化比 ≈1.5，GCI ≤ 5%
4. [[交付验收与报告规范]] — 报告章节须符合 GB/T 33582-2017
5. [[FDE角色与工作标准#五po-c-设计原则]] — PoC 门槛是方法论门槛，不是结果门槛

### 客户发来一个 STEP 文件，我要开始建模

4. ⚠️ **先问**：这个几何有装配结构吗？材料指派还在吗？（意图已丢失多少）

### 我要评估一个代理模型能不能上
1. [[代理模型与神经算子工程化#交付前必做的十项验证]]
2. 重点看**外推复杂度**（2-Wasserstein 距离）与**谱误差分解**
3. 是否有 NAFEMS Data Driven Benchmark 的跑通结果？
4. ⭐ **路线层面的失败模式**：[[物理AI技术路线全景#41-a2-神经算子外推即失效最致命]] —— 外推失效是**结构性缺陷**，不会因训练更久而消失

### 我要用 LLM 生成 CAD 或几何
1. ⛔ **先读** [[CAD与几何工程#八-llm-for-cad-的真实边界2026]] — IR 2% 但 IoU ≈ 0 的陷阱
2. **验收标准不能用"能跑"**，要用 [[CAD与几何工程#七-几何内核作为真值裁判--cad-领域独有的验证优势|六层内核验证]]
3. [[LLM在物理仿真中的角色边界]] — 数值溯源强制机制
4. ⭐ **路线层面**：[[物理AI技术路线全景#45-d1d2d4-llm语法可以物理不行]]

### 客户质疑"你们比 ANSYS 快 80%"
1. [[100-物理AI产品与领域/030-竞品与市场/竞品与市场情报#宣传数字的证伪清单]]

3. 提醒：DPW-6 显示即使同一基准同一网格，7 个独立 CFD 码的 CL 仍有 1% 差异，18% 提交为离群值
4. ⭐ **更狠的对照**：[[100-物理AI产品与领域/030-竞品与市场/竞品地图#七-三句可直接对外的竞争叙事]] —— **西门子自己承认 PhysicsAI 不适用于安全关键应用**

### 我要写一份行业标准或竞品分析

4. **CAx-IF 推荐实践清单**（17 份一手 PDF，含 Persistent IDs v1.8）—— CAD 侧的标准入口
5. ⭐ **CAD-CAE 一体化的真实水位**：[[CAD与几何工程#九-cad-cae-一体化谁真正做通了]]
6. ⭐ **竞品分析的方法论**：[[100-物理AI产品与领域/000-专家作业标准-四问#13-v3-新增竞品层面的额外工作]]

### 我在设计 Solid 的 API

## ⚠️ 已核查出的错误（反例保留，勿再犯）

| 错误类型 | 实例 |
|---|---|
| **编号幻觉** | ⭐ **本轮 18 个编号中 9 个被证伪**（含提问时给出的 DeepONet、Causal PINN、PINO） |
| **标准号错误** | JT 是 **ISO 14306**（已拆 4 个分部分，2012/2017 已撤销），不是 ISO 14343（焊接标准） |
| **同名论文** | Text2CAD 有两篇（`2409.17106` / `2411.06206`）；CAD-Coder 有两篇 |
| **开源误分类** | Onshape（商业 SaaS）、OpenBuilds（硬件+CAM）不是开源 CAD |
| **企业混淆** | Cadence 是芯片 EDA，不是机械 CAD |
| **API 版本虚构** | Assistants API v3 不存在；该 API 已于 2026-08-26 关停 |
| **榜单不存在** | 无"DesignNet / Fusion 360 Gallery 排行"；可用的是 CADGenBench / BenchCAD |
| **⭐ 竞品不存在** | Aithena 无多物理场仿真公司；Simcentrica 实为斯里兰卡军工仿真；⭐ **SimScale 至今独立，未被西门子收购**（西门子收的是 Altair） |
| **⭐ 公司归属错误** | 云道智造创始人是屈凯峰（清华电机系博士），**与涂子昕无关**；UniX AI 是优理奇机器人（本体厂，不做仿真） |
| **⭐ 对标对象错误** | AICube 的国际可比对象是 **51WORLD**（物理直觉世界模型 + 行业落地），不是 PhysicsX |
| **⭐ 日期错误** | 3DEXPERIENCE AI 商业版是 **2026-07-23**，不是 2025-10 |
