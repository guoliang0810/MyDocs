# 专家作业标准：物理 AI × CAD/CAE 落地

> **v2.0（2026-10-26）**：从"泛物理AI"升级为"**物理 AI × CAD/CAE 落地**"交叉领域聚焦版。
> v1 的最大空白是**完全没有 CAD/几何侧**——而这恰恰是落地的真正入口。
>
> **本库的元技能文档。** 不记录某个具体知识，而是记录：
> **面对物理 AI × CAD/CAE 落地的任何一个同类问题，顶尖专家会多做什么、拿什么原始素材、用什么方法、怎么被独立验证。**

---

## 零、为什么这个领域特别需要"作业标准"

这个领域有一类致命错误：**看起来很合理，但实际不成立。**

本次重构实测（全部有据可查）：

| 错误类型 | 实例 | 后果 |
|---|---|---|
| **编号幻觉** | 4 个看似专业的 arXiv 编号里 **3 个指向完全无关的论文** | 技术评审当场暴露 |
| **标准号张冠李戴** | JT 被写成 ISO 14343（实为焊接标准；JT 是 **ISO 14306**） | 引用整段作废 |
| **产品名幻觉** | "Assistants API v3 (2026)" 不存在；"Google Workspace Agents"、"Android Intent 扩展" 均为虚构 | 文档可信度归零 |
| **分类错误** | Onshape 被列为"开源 CAD"（实为商业 SaaS，$1500/人/年起）；OpenBuilds 被列为 CAD 产品（实为硬件+CAM） | 选型误判 |
| **企业名混淆** | Cadence（芯片 EDA）被当作机械 CAD 一体化厂商 | 战略误判 |
| **⭐ "可执行=正确"** | Text2CAD-Bench：领域模型 **IR 低至 2%，但 CD ≈ 220、IoU ≈ 0** | ⭐ **几何完全不对但看起来一切正常** |
| **精度通胀** | "仿真速度提升 80%" 无法给出基准算例、网格规模、精度等效性证明 | 客户一追问就崩 |

> ⭐ **所以这个领域的"专家作业标准"不只是更严谨，是生存必需。**

# 一、专家会额外开展哪些我本次没有要求的工作？

> **这一问最容易被跳过，但价值最高。**
> 你要求的是"回答问题"，专家做的是"**先把问题定义对**"。

## 1.1 通用规律（跨领域通用）

| # | 专家额外做的事 | 为什么必须做 |
|---|---|---|
| 1 | **反向提问 + 建立问题契约** | 用户的问题通常是模糊的；专家第一件事是把它变成可判定的 |
| 2 | **定义"成功"的度量** | 没有可判定的成功标准，交付就无法验收 |
| 3 | **主动找出"这个问题可能是错的"** | 顶尖专家的第一反应常是"你确定要这么做吗" |
| 4 | **区分"能做的"和"该做的"** | 技术可行 ≠ 商业合理 |
| 5 | **画出失败路径与降级策略** | 专家会问"这个做不成的时候怎么办" |
| 6 | **设定退出机制** | 保护客户，也保护自己不被预期绑架 |
| 7 | **识别可沉淀的资产** | 一次性交付是浪费，沉淀才是复利 |
| 8 | **明确"不做什么"** | 范围控制是交付质量的第一道闸 |

## 1.2 ⭐ 物理 AI × CAD/CAE 落地的专属展开

### 环节 A：前期——几何是第一道闸，不是最后一道

| 专家额外做的事 | 具体内容 |
|---|---|
| **几何缺陷成本量化** | 3 个小面 + 1 条小缝 → 最小面面积比小 5 个数量级 → 单元数 2×、核时 4× |
| **入口预检规则** | 自相交 / 非流形 / 短边 / 小面 / 缝隙 / 尖角，各自的判据与工具 |
| **几何清理优先级** | 缝合容差**逐步增大**；小特征阈值 **< 全局网格尺寸 1/5** |
| **defeature 的影响量化** | 用双向 Hausdorff + 体积/面积守恒证明"简化对目标物理量影响 < X%" |
| **优化空间 vs 允许空间切分** | 可变参数 = 优化空间；工艺/法规约束 = 允许空间 |
| **DFMA 前置** | C919 复材机翼公开材料明确采用"面向制造装配的设计（DFMA）理念" |
| **⭐ 把"不能"做成合法交付物** | 在航空/医疗场景，一个基于不可信模型的减重承诺直接导致适航/临床风险 |

→ 详见 [[CAD与几何工程]] §一~§三

### 环节 B：建模——网格质量三档基线

| 专家额外做的事 | 具体内容 |
|---|---|
| **建立网格质量阈值表** | 理想/可接受/拒收三档（长宽比、偏斜度、雅可比、翘曲、锥度、内角、正交质量、形状因子） |
| **明确口径差异** | ANSYS Orthogonal Quality vs Abaqus Jacobian，同网格不同结论 |
| **渐进式划分** | 粗网格跑通 → 看质量报告 → **只局部加密不合格区**，不全局加密 |
| **结果反查** | 应力云图**叠加网格质量云图**；关键位置网格差则标注"不确定" |
| **网格收敛研究** | 3 档网格，关键输出量收敛 <1–2% |
| **敏感性分析** | 网格质量-结果敏感性（在不良单元附近加密看结果是否漂移） |

→ 详见 [[CAD与几何工程]] §四

### 环节 C：⭐ 代理模型——"可执行 ≠ 正确"的镜像陷阱

物理 AI 在 CAD/CAE 落地有**两个独立的正确性陷阱**：

| 陷阱 | 表现 | 判官 |
|---|---|---|
| **代码可执行 ≠ 几何正确** | IR 2% 但 CD ≈ 220、IoU ≈ 0 | ⭐ **几何内核** |
| **模型能跑 ≠ 物理可信** | 代理模型在训练域外误差放大 6×（BC）/ 3.9×（强非线性） | ⭐ **基准 + 试验** |

**专家额外做的事**：

| # | 动作 | 判据 |
|---|---|---|
| 1 | **外推失效定量检测** | 2-Wasserstein 距离（NeU-PINN），画出"拒绝服务区" |
| 2 | **频谱失效诊断** | 双重扫描（加密网格 × 加密 Fourier 模态） |
| 3 | **模态消融** | 8→16→32 模态，OOD 频率误差**单调上升**（反直觉） |
| 4 | **长时 rollout 稳定性** | 超出训练时间窗 2× → 相对误差增长 1.44× |
| 5 | **训练分布覆盖矩阵** | BC 外推 6× 误差；强非线性 3.9× 误差 |
| 6 | **误差分解** | ⭐ 分离"离散化误差"与"学习误差" |
| 7 | **与求解器耦合验证** | 收敛性一致性、守恒量漂移、**切换边界不连续性** |
| 8 | **不确定度随产品交付** | 分布无关、有限样本保证的校准带 |
| 9 | **用中立基准自证** | NAFEMS Data Driven Benchmark（vendor neutral） |
| 10 | **内核级几何校验** | ⭐ 六层验证（见下） |

**几何侧六层验证（CAD 领域独有的判官）**：

| 层 | 检查 | 失败即 |
|---|---|---|
| L1 | 程序可执行 | IR 计入 |
| L2 | `BRepCheck_Analyzer.IsValid()` | 判 0 |
| L3 | 水密 / 无裸边 | 判 0 |
| L4 | 流形可网格化 | 判 0 |
| L5 | 量守恒（`BRepGProp`） | 容差判定 |
| L6 | 拓扑不变量（Betti 数 / 欧拉数 / 亏格） | 与目标一致 |

→ 详见 [[CAD与几何工程]] §七、[[代理模型与神经算子工程化]]

### 环节 D：验证——三个层次的证据

| 层次 | 问什么 | 判官 |
|---|---|---|
| **存在性** | 这个编号/标准/产品/价格真的存在吗 | arXiv abs 页、ISO 目录页、官方 release notes、政府采购网原公告 |
| **准确性** | 说的属性和数字对吗 | 标准正文、原始公告、官方文档 |
| **有效性** | 它真能支撑我的结论吗 | ⭐ **NAFEMS 基准 + 试验/盲预测 + 几何内核** |

### 环节 E：⭐ 意图传递——CAD→CAE 到底丢了多少

专家会做**往返实验**而不是问"格式支持吗"：

1. 原生 CAD → 中性格式 → 回到另一 CAD/CAE
2. 比对：装配层数与实例数、零件名、材料指派、基准体系、**PMI 语义（不是图形）**、Validation Properties（体积/面积/质心）、运动副、运动学求解结果
3. 报告"丢失率"，**当作供应商验收指标**

**硬机制**：Persistent ID（CAx-IF v1.8，2026-03-13）——
STEP 用 `V5_UUID_ATTRIBUTE`、QIF 用 `EntityExternalIds`，
正确实施可达 **100% 可追溯**；CAx-IF R57J 测试轮 **STEP 数据交换成功率 97%**。

→ 详见 [[CAD与几何工程]] §十三

### 环节 F：交付——证据包与责任边界

| 专家额外做的事 | 内容 |
|---|---|
| **结果血缘包** | 求解器版本/网格/输入卡/材料卡/边界条件/求解日志/GCI/迭代收敛历史/权重 hash/后处理脚本/假设清单 |
| **证据等级声明** | L-1 方案比选 / L-2 设计输入 / L-3 符合性证据（三者法律含义完全不同） |
| **三层签署链** | CAE 分析师（计算正确）→ 方法负责人（模型适用）→ 项目责任人（**唯一承担用途责任**） |
| **失败工况记录** | 哪些工况算不出来、为什么 |
| **迭代收敛历史** | ⭐ DPW-6 评审已将其列为**缺陷** |

### 环节 G：复盘与产品化沉淀

| 专家额外做的事 | 内容 |
|---|---|
| **结构化复盘写入 PRD** | 不是口头 |
| **未沉淀资产清单** | ⭐ 最容易漏的一栏 |
| **FMEA（含"求解不收敛"本身）** | RPN = S×O×D |
| **L1–L4 四层沉淀** | L1 模板 / L2 参数库 / L3 求解器插件化 / L4 API-SDK |
| **⭐ CI 化 V&V** | 每次求解器/算法变更自动跑 NAFEMS 基准 + 自有回归集，**GCI 或对标偏差超阈值则阻断合并** —— 这是把 V&V 从"文档"变成"工程"的唯一方式 |

### 环节 H：⭐ 战略层——诚实评估差异化

专家会做**竞争定位的诚实评估**，而不是自说自话：

**当前 CAD-CAE 一体化的真实水位**（详见 [[CAD与几何工程]] §九）：

| 层级 | 玩家 | 一体化程度 |
|---|---|---|
| L4 无需导出转换 | 达索 MODSIM、西门子 Simsolid | ⭐⭐⭐⭐⭐ |
| L3 装配级 FEA 内嵌 | Onshape Simulation | ⭐⭐⭐ |
| L3 AI 代理仿真 | Ansys SimAI / Discovery | ⭐⭐⭐ |

> ⭐ **结论**：真正做到"无需导出、无需网格、装配 mates 直接变运动学、结果随模型版本走"的只有三家。
>
> **所以护城河不能是"我们也能在 CAD 里跑仿真"。** 真正的差异化在：
> 1. **AI 代理模型替代多少求解器次数**（SimSolid 是确定性无网格 FEM，不是 AI）
> 2. **C919 级复材的层合板本构 + 变刚度设计**（SimSolid/Onshape 都不覆盖）
> 3. **医疗骨科完整物理链路**（CT 分割 → 骨缺损重建 → 术前规划 → 术后受力仿真）

→ 详见 [[100-物理AI产品与领域/010-产品与战略/产品矩阵与定位]]

# 二、专家会使用的原始一手素材？

> **核心区分**：
> - **二手材料** = 别人加工整理好的结论（新闻稿、综述、博客、课件、笔记）
> - **一手素材** = **原始来源本身**，可被独立打开、独立核验
>
> ⭐ **判断标准只有一条：你能打开原始文件，看到未经转述的事实吗？**

## 2.1 通用的一手素材类别

| 类别 | 是什么 | 为什么专家直接用 |
|---|---|---|
| **原始文献全文** | 论文 PDF / 预印本原文 | 摘要会骗人，方法与数据不会 |
| **标准正文 + 生命周期页** | 标准组织正式文本 | 解读文章常漏条款号与版本状态 |
| **原始数据集** | 数据文件 + 数据卡 | 论文里的图是二次加工 |
| **原始日志/工单/邮件** | 一手的现场记录 | 复盘的唯一真相来源 |
| **招标与采购公告原文** | 政府采购网公告 | 中标公告 = 真实成交价，二手转述常错 |
| **官方 release notes** | 版本变更记录 | 产品生命周期的唯一权威 |
| **一手访谈/会议纪要** | 原始录音与逐字记录 | 二手总结丢掉了犹豫和分歧 |
| **代码仓库提交历史** | git log | 变更时间线与真实演进 |

# 五、⭐ 落地为默认流程：编号与引用核验清单

> **本次最贵的一课：调研 4 个论文编号，3 个是错的；一个标准号写错；两个产品分类错误。**
> 成本极低，收益极高——把它固化成流程。

### 强制流程

> **知识库中每条 arXiv / 标准号 / 算例名 / 价格 / 产品名 / 开源分类，
> 必须经过"打开原始页面确认"这一步。未核实的一律标 `⚠️未核实`，不许凭记忆写。**

### 核验清单（逐条过）

- [ ] **论文**：打开 `arxiv.org/abs/<ID>`，核对**标题**与**作者**（不只是编号存在）
- [ ] **论文**：看 Comments 字段确认是否已发表（避免引用未评审预印本）
- [ ] **论文**：查是否**有同名论文**（Text2CAD 两篇、CAD-Coder 两篇）
- [ ] **标准**：查 ISO/ASME 目录页，核对**标准号 + 版本年份 + 现行/已撤销状态**
- [ ] **标准**：查是否为**分部分**标准（JT 是 14306-1/2/3/4，不是单一 14306）
- [ ] **标准**：查是否在修订中（ISO/DIS、ISO/CD）
- [ ] **价格**：回到**原始公告页**核对金额、日期、规格、并发数
- [ ] **产品**：查**官方 release notes / changelog**，确认功能与生命周期
- [ ] **产品**：确认**商业 vs 开源**，读官方定价页与 License
- [ ] **开源库**：用 GitHub API 查**最后推送日期**（识别停更项目）与 **LICENSE 实际内容**
- [ ] **数据**：检查数据集的**版本号与 DOI**（v2 与 v3 可能内容不同）
- [ ] **基准**：确认基准的**已知解/真值带**，而不只看算例名
- [ ] **许可证**：确认**商用是否受限**（AGPL / GPL 静态链接 / 双许可）
