# 文本处理三剑客 (Grep, Sed, Awk) 实战

在运维开发中，日志分析和数据清洗是高频场景。熟练掌握三剑客能让你在处理 GB 级日志时游刃有余。

## 1. Grep: 文本搜索

Grep (Global Regular Expression Print) 用于高效搜索文本。

### 常用参数
- `-v`: 反向选择（排除匹配行）
- `-i`: 忽略大小写
- `-E`: 支持扩展正则表达式 (等同于 egrep)
- `-o`: 仅输出匹配部分
- `-A n / -B n / -C n`: 输出匹配行的 后n行 / 前n行 / 前后n行

### 实战案例
**场景**: 从 Nginx 日志中找出所有 500 错误的 IP 地址。
```bash
grep " 500 " access.log | awk '{print $1}' | sort | uniq -c | sort -nr
```

**场景**: 查找代码中所有 TODO 注释。
```bash
grep -rE "TODO|FIXME" ./src
```

## 2. Sed: 流编辑器

Sed (Stream Editor) 用于对文本流进行查找、替换、删除。

### 核心命令
- `s/old/new/g`: 全局替换
- `d`: 删除行
- `p`: 打印行
- `-i`: 直接修改文件内容 (慎用!)

### 实战案例
**场景**: 批量替换配置文件中的 IP 地址。
```bash
sed -i 's/192.168.1.100/10.0.0.5/g' config.yaml
```

**场景**: 打印文件的第 10 到 20 行。
```bash
sed -n '10,20p' data.txt
```

**场景**: 删除所有空行。
```bash
sed '/^$/d' file.txt
```

## 3. Awk: 文本处理语言

Awk 是一门完整的编程语言，特别适合处理列式数据。

### 基础语法
`awk 'pattern {action}' file`

- `$0`: 整行内容
- `$1, $2...`: 第一列, 第二列...
- `NR`: 当前行号
- `NF`: 当前行的字段数 (列数)
- `-F`: 指定分隔符 (默认空格)

### 实战案例
**场景**: 统计 Nginx 日志中每个接口的访问耗时 (假设耗时在最后一列)。
```bash
awk '{sum+=$NF; count++} END {print "Avg time:", sum/count}' access.log
```

**场景**: 检查磁盘使用率超过 80% 的分区。
```bash
df -h | awk 'NR>1 {print $5, $6}' | sed 's/%//' | awk '$1 > 80 {print "Warning: Disk full on " $2}'
```

**场景**: 格式化输出 /etc/passwd 中的用户名和 UID。
```bash
awk -F: '{printf "User: %-15s UID: %s\n", $1, $3}' /etc/passwd
```
