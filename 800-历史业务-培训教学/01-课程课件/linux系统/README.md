# Linux 运维开发实战 - 进阶之路

> [!INFO] 课程定位
> 本课程旨在帮助测试开发/运维工程师从基础的 Linux 操作进阶到 **高阶运维开发** 阶段。
> 内容涵盖 Shell 高级编程、内核性能调优、网络故障排查及云原生技术栈。

## 📅 课程大纲

### [[01-基础入门]] (Foundation)
- 文件与目录管理、权限控制
- 远程管理与 SSH
- 基础系统信息查看

### [[02-Shell编程进阶]] (Advanced Shell)
- **文本处理三剑客**: Grep, Sed, Awk 深度实战
- **高级编程**: 函数封装、数组操作、调试技巧
- **实战**: 编写自动化巡检脚本、日志分析脚本

### [[03-系统内核与性能调优]] (Kernel & Performance)
- **CPU**: Load Average, Context Switch, 火焰图分析
- **Memory**: Swap 机制, OOM Killer, Page Cache 调优
- **I/O**: iostat, 磁盘调度算法, 文件系统选型 (Ext4 vs XFS)
- **Kernel**: sysctl 参数优化

### [[04-网络原理与故障排查]] (Network & Troubleshooting)
- **协议栈**: TCP 三次握手/四次挥手状态机分析
- **工具**: Tcpdump 抓包与 Wireshark 分析, Netstat/SS
- **安全**: Iptables/Nftables 防火墙策略

### [[05-容器化与云原生]] (Cloud Native)
- **Docker 原理**: Namespace 隔离, Cgroups 资源限制, UnionFS
- **Kubernetes 基础**: Pod, Service, Deployment 概念
- **实战**: 编写 Dockerfile, 搭建 K8s 集群
